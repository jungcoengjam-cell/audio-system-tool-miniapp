# 音频系统计算工具

微信小程序项目，用于音频系统常用参数计算。

当前版本：`5.0.1`（已上传正式版，用户于 2026-09-19 确认）。更新内容见[5.0.1 更新说明](docs/release-notes-5.0.1.md)。

小程序已扩展为音频、视频与舞台灯光现场工具。当前正式版包含八个计算模块和独立产品资料库；本地源码另有尚未发布的“接线助手”和“项目布线”入口。探索页提供配套的图解知识内容。

## 接线助手（未发布）

接线助手为独立工具，不属于计算或记录归档模块。当前模型列出 6 类输出与 7 类输入，共 42 种接口组合：21 种可直接形成接线方案，另 21 种须先明确选择。完成所需确认后可显示 67 种方案；这是条件分支数量，不代表 67 种设备组合都普遍兼容。

功能覆盖双向平衡/非平衡连接。平衡输出接非平衡输入时，只提供“冷端与输入回路连接”这一条件方案；必须明确选择并确认设备手册允许，未确认前不生成方案。接线助手不提供冷端悬空接法。3.5 mm TRS 立体声转单声道直连接法只取 L 或 R，可能遗漏另一声道内容；需要两边内容时先由播放设备或混音器合成为单声道，L/R 不可直接并接。单声道输出分送双输入时可选择 L、R 或两路。未连接的针脚会明确标注。复制接法与生成的图片采用相同条件选择。端口用途、冷端接法和并联负载均须按具体设备说明书确认，接头外形本身不能确定信号类型。接法依据见[接线助手方法说明](docs/audio-wiring-method.md)，本轮自检修复与整合验收状态见[接线助手模块审计](docs/audio-wiring-module-audit-2026-09-20.md)。早期冷端分支调整和 91 方案交叉核对记录仍见[冷端回路方案更新](docs/audio-wiring-cold-return-only-2026-09-20.md)与[交叉接线历史验收](docs/audio-wiring-cross-2026-09-20.md)，保留为历史证据。

接线助手尚未发布，不属于已上传的 `5.0.1` 正式版。本轮完整回归、102 个浏览器页面状态、754 次绘图与原生模板/样式编译通过；修复内容及待完成的真机/电测事项见[接线助手模块审计](docs/audio-wiring-module-audit-2026-09-20.md)。

## 项目布线（未发布）

项目详情提供“通道与线缆”入口。工具页音频行新增“通道与线缆”，与“接线助手”相邻并排在前两位；点击“通道与线缆”进入布线。工具页直入时，有全局当前项目就打开该项目；没有时，可在布线页底部弹层选择或新建项目。布线页顶部也可在本页切换项目；普通选择不会修改全局当前项目，新建项目沿用既有的“新建即当前”行为。

布线按设备和端口维护点对点线路，可新增、编辑、复制和批量创建，并使用稳定的 A001 线号。清单记录制作方式、线材规格、两端接头、长度、状态与备注；材料汇总分别整理成品线、散线和散线接头，并生成线路两端对应的标签。用户可复制完整文字清单，也可生成分页布线图片。项目首页默认展示现场项目，仍可切换到收藏；每张项目卡提供“布线”“报告”直达入口和线路数量。

每个项目的布线数据保存在本机项目数据的 `wiringSchedule` 字段，按项目单独读取和保存；删除项目时布线随项目数据一并移除。项目布线仍处于本地未发布开发状态，不属于 `5.0.1` 正式版。双入口更新说明及验收记录见[布线入口更新](docs/wiring-entry-update-2026-09-20.md)；初版数据模型与材料规则见[项目布线说明](docs/project-wiring-v1-2026-09-20.md)。新增功能与独立的接线助手保持分开，不修改现有计算校准或产品资料库。

## 开发规则分层

- 根目录 `AGENTS.md` 是 Codex 的项目执行入口，负责区分 UI 规则与核心业务规则。
- 根目录 `DESIGN.md` 只约束界面视觉、交互、动效、响应式和可访问性。
- `docs/*.md`、`utils/*.js`、`data/*.js` 和 `tests/release-check.js` 继续作为计算公式、产品数据、业务逻辑与发布基准的依据。
- UI 优化不得顺带修改或覆盖核心算法；同时涉及两类规则时，应分别核对并执行回归测试。

## 当前功能

- 功放型号选择：来自产品库
- 音箱型号选择：来自产品库
- 功放和音箱支持关键词搜索
- 功放和音箱支持按型号系列分类筛选
- 独立产品资料库：
  - 收录 38 款功放、148 款实际音箱和 26 款摄像机型号，支持分类切换、关键词搜索、系列筛选、参数能力筛选和最近查看。
  - 支持同时选择 2～3 款同类产品进行参数对比；未在说明书中提供的参数继续明确显示为缺失。
  - 产品详情显示当前已录入参数、说明书来源、规格页码、统一复核日期和明确的待补充参数。
  - 已复核的会议室候选音箱额外显示最大声压级、水平/垂直覆盖角和候选角色。
  - 可从限幅器、声压级型号选择器查看资料，也可从产品详情直接带入对应计算模块。
- 每通道音箱数量：1、2、3、4 只
- 连接方式：并联、串联；每通道 1 只音箱时不显示连接方式
- 功放模式：立体声/单通道、桥接
- 输入灵敏度：1 V（2.2 dBu）、2 V（8.2 dBu）
- 输出结果：
  - 限幅器阈值，单位 dBFS
  - 当前总阻抗
  - 音箱总额定功率
  - 目标输出电压
  - DSP 模拟输出电平
  - Attack 建立时间推荐值
  - Release 释放时间推荐值
- 声压级与功率估算：
  - 音箱型号搜索与系列分类
  - 自定义测量距离与常用距离声压级表
  - 按说明书灵敏度和额定功率计算同型号单只或多只音箱的自由场理论声压级
  - 支持常规叠加与理想同相叠加两种模式
  - 提供听感量级与会议类最大声压级数值参考，不作为工程验收结论
- 线材选型：
  - 支持定压广播喇叭线与专业音箱金银线两种模式。
  - 定压广播按额定总功率 × 1.5、最远单程距离和室内/室外条件，匹配公司线材对照表。
  - 专业音箱按额定总功率 × 1.5 推荐金银线规格，并提示 100 m 距离和 1500 W 对照表上限。
- 场地扩声预估：
  - 仅适用于平顶、单层、规则矩形会议室；输入长、宽、高、首排听音距离，并选择会议类一级/二级目标。
  - 只推荐定覆盖点声源 L/R 主扩与后区补声，不自动搭配功放。
  - 报告/培训型在 6 组有限对称前置位置与指向候选中稳定排序，并使用未舍入 raw H/V 几何需求筛选标称产品角；不把候选结果写成全局最优。
  - 自动绘制矩形平面、逐只编号的主扩/补声位置、固定耳高理想角包络及等向距离能量示意图；全部声学覆盖状态仍待产品指向性与现场核验，不替代专业预测软件或现场测量。
  - 补声传播复核复用既有源位置、源姿态和 `aimDepth` 参考排，在听音区横向 `1/4`、`1/2`、`3/4` 三点内比较前级（主扩+更靠前补声）与当前补声的最近参考源；按 `(d_front - d_fill) / 343 × 1000` 给出仅含声传播的 `deltaMs`，记录源标签。无共同几何范围时显示“暂不可比较，先复核指向”，无补声时隐藏整段复核。详情和长图使用轻量缓存，布局图与完整复制按需复用完整 plan。详见 [`docs/venue-handoff-review-2026-09-14.md`](docs/venue-handoff-review-2026-09-14.md)。
  - 【5.0.0 历史开发检查】当前补声复核专项与发布回归已记录：`43` 个有效场景、`5` 个拒绝输入、`46` 组/`138` 点、`51` 个不可比较点、`21` 个前组补声参考；`88` 个页面状态、`21` 个 WXML、`22` 个 WXSS；发布包 `1,671,754 bytes`，主包 JS `754,495 bytes`。这些是几何、控制器、视觉状态、编译和包体证据，不等同于微信真机、厂家模型或现场声学验证。证据见 [`docs/verification/venue-handoff-2026-09-14/final-audit.json`](docs/verification/venue-handoff-2026-09-14/final-audit.json) 与 [`docs/venue-handoff-review-2026-09-14.md`](docs/venue-handoff-review-2026-09-14.md)。当时版本号保持 `5.0.0`，该轮改动尚未发布；当前版本见本文档开头。
  - 面积超过 300 m²、主扩服务纵深超过 20 m、层高超过 6 m，或为礼堂、音乐厅、阶梯/分层、异形场地时，不输出自动组合，需由方案工程师专项设计。
  - 围桌讨论型提供平面分区和侧视覆盖预检查，显示安装高度、坐席耳高、垂直包络需求及壁挂初始下倾角参考。
  - 【5.0.0 历史开发检查】新增可选单链路 PAG/NAG 传声增益复核：页面仅用于 Voice Lift，默认关闭并要求填写 `ds/d0/dn/d1/d2` 五项距离与 `nom`；不自动把人数当作 NOM 或默认 `NOM=1`。不完整时保留基本布局但禁止复制、生成、收藏和加入项目；页面、报告、原生编译与完整发布自检已完成，最终有效包 `1,690,633 bytes`、主包 JS `768,946 bytes`、WXML `197,008 bytes`，真机与现场声学未测。当时版本号保持 `5.0.0`，该轮改动尚未发布；当前版本见本文档开头。
- 摄像机视场角计算：
  - 已逐页复核 21 份说明书并录入 26 个实际型号；其中 16 个型号同时具备厂家水平/垂直视场角，可进入完整安装计算，另有仅具备水平角的型号可做水平覆盖预估。
  - 支持“地面区域”和“垂直平面”两种安装反算：输入需要拍全的区域，输出当前独立水平/垂直视场角覆盖模型下的理论最小距离与镜头中心建议高度。
  - 地面区域同时校核近端/远端地面与人物最高点；垂直平面按目标宽高和底边离地高度校核。
  - 支持自动建议高度或输入已有固定安装高度，并提供 0%～20% 构图安全余量，默认 10%。
  - 自定义摄像机可直接输入水平/垂直视场角，或输入有效传感器宽高与实际焦距。
  - 库内水平角和垂直角必须直接来自说明书；缺少垂直角的型号仅做水平覆盖预估并标注未校核，不做画幅比例、对角角度或变焦倍数推算。
  - 结果为理想光学几何覆盖，不等同于人脸、文字或细节的有效识别距离。
- LED 大屏尺寸预估：
  - 输入墙体宽高、上下最低预留、四周包边和最近观看距离，屏体默认水平居中；包边默认每边 5 cm。
  - 支持 16:9、4:3、21:9、16:10、32:9 五种常用目标画面比例。
  - 支持 320 × 160 mm 模组、640 × 480 mm 常规箱体和 600 × 337.5 mm 高端 A 系列箱体整数拼装。
  - 在安装外尺寸不超过墙面的前提下，优先从目标比例误差不超过 5% 的方案中选择最大净屏。
  - 点间距可由系统从 P1.25、P1.53、P1.86、P2.0 中推荐，也可指定后校核观看距离；特作规格不进入常规推荐。
  - 输出净屏尺寸、含包边安装外尺寸、拼装数量、墙面余量、估算分辨率和按比例墙面示意图。
  - 可在本地生成高清方案长图，预览后直接转发或保存到相册；结果图片不上传云端。
- 系统增益结构助手：
  - 从产品库读取功放说明书确认过的输入灵敏度或电压增益档位，不允许跨型号使用未提供的档位。
  - 按 `0 dBFS = +18.4 dBu` 标定，将 DSP 目标峰值与功放额定输出输入点对齐，并区分厂家输入灵敏度计算和额定功率、电压增益反算。
  - 支持选择 DSP 最终输出或功放输入电平控制作为唯一衰减执行位置，避免两处重复施加衰减。
  - 同一输入灵敏度档位得到相同对齐衰减属于预期结果；功放型号用于读取合法档位与说明书来源，电压增益型功放才结合型号、模式、负载和额定功率计算。
- DMX 灯具地址编址：
  - 固定从 A 域开始，可设置 A 域起始地址；超过 512 时按 A、B、C、D 自动跨域，并按灯具名称、单台通道数、数量建立多个顺序分组。
  - 自动输出每台灯具的首地址和通道占用范围；当前域剩余地址不足以容纳完整灯具时，自动转入下一域。
  - 显示域尾保留地址、跨域提示和下一可用地址；现场仍需核对灯具通道模式、控台 Patch 与节点域号。
- 现场排查：
  - 提供“音箱没声音”和“灯具不受控”两个固定问题树，分别按输入/输出与保护/连接、DMX 信号/地址通道/域和控台状态逐步引导观察。
  - 结果按编号列出检查步骤；“已恢复／仍异常”是用户确认反馈，不是自动检测结论。
  - 结果页可展开排查路径、查看每一步答案，并修改某一步后从该处分支继续；支持返回上一步、重新开始和显示当前节点的上次选择。
  - 灯具地址相关结果可跳转到 DMX 灯具地址编址工具；页面提示静音、断电并避免拆机。
- 八个计算工具均支持复制完整结果，并在本机记住最近一次有效输入；可从首页恢复默认设置。
- 项目与记录：
  - 普通计算不会自动保留历史；记录仅在收藏或归入现场项目时持久保存，相同参数不会重复生成记录。
  - 支持收藏常用计算，并从记录中恢复原参数重新计算。
  - 支持创建本地现场项目，把记录系统支持的八个工具模块结果归档后一次性复制汇总。
  - 项目详情可在本地生成汇总长图，预览后直接转发或保存到相册；长图只展示精简摘要，不上传云端。
  - 项目可保存场地尺寸和扩声目标，显示八个可归档模块的完成进度，并从项目直接继续计算。
  - 同一模块的两条项目记录可以进行核心输入差异对比。
  - 收藏或已归入项目的记录会持续保留；无归属的普通计算不会作为项目历史保存，所有数据只保存在用户手机本地。

当前产品库已复核公司资料中的 38 个功放型号、148 个实际音箱型号和 26 个摄像机型号。`TS-603B-603W` 已确认是双型号说明书标题而非真实产品型号，现按 `TS-603B`、`TS-603W` 分别保留。页面会按产品库实际数据展示可选型号。

## 重要基准

DSP 输出限幅器采用以下基准：

```text
0 dBFS = +18.4 dBu
```

该值采用本次实测设备的校准条件；原始测量条件与验证边界见 [`docs/calculation.md`](docs/calculation.md)，不视为所有处理器通用值。

当前计算未加入额外安全余量。

## 当前限制

- 功放只有说明书中明确给出的 4Ω、8Ω、16Ω功率数据；没有数据的负载不会插值计算。
- Attack 建立时间、Release 释放时间在用户选择 DSP 输出通道高通频率（HPF）后自动给出推荐值；未选择 HPF 不影响限幅阈值计算。时间值不是国家标准或 AES 固定标准。
- 声压级结果是单只音箱、自由场、额定功率下的理论估算，现场结果应以测量麦克风为准。
- 功放功率来自说明书标注的 20 ms 脉冲测试值，和长期连续功率不是同一个概念。
- DMX 编址结果依赖用户填写的灯具通道模式；灯具切换模式后必须重新计算并核对控台 Patch。
