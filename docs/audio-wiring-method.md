# 接线助手的接法范围与依据

接线助手覆盖六类输出和七类输入的 42 种常见模拟音频 LINE 接口组合。场景名称只用于识别信号方向；外形相同不代表电平、平衡拓扑、接地设计或端口用途相同。施工前须核对两台设备的具体型号说明书。

## 模型状态与选择

所有 42 种已知接口组合都有明确状态：21 种可直接显示接线，另 21 种必须先作选择。对所有相关选择都完成后共有 67 个可显示方案，其中 46 种需要选择。`ready` 才能显示连线或复制；`needs-choice` 和 `unsupported` 不提供连接线，且不能复制。未知或非字符串接口 ID 均为 `unsupported`。

需要选择的组合如下：

| 接口组合 | 必选项 | 选项含义 |
| --- | --- | --- |
| 平衡输出 → 单 RCA/TS 输入 | `outputMode` | 确认两台设备手册明确允许将 − 冷端与屏蔽分别接入非平衡输入回路，并在输入端汇接。 |
| 平衡输出 → 双 RCA/TS 输入 | `outputMode` 与 `destinationChannel` | 先确认冷端与屏蔽在输入端汇接得到两台设备手册允许，再选择只接 L、只接 R，或把一个输出分送到 L/R 两个彼此独立的高阻 LINE 输入。 |
| 3.5 mm TRS 立体声输出 → 单声道平衡或非平衡输入 | `sourceChannel` | 从 L/T 或 R/R 中只选一路；另一声道信号输出保持未接。 |
| 单声道 RCA/TS 输出 → 双 RCA/TS 输入 | `destinationChannel` | 只接 L、只接 R，或分送至两个独立高阻 LINE 输入。分送不是混音，并须核对并联负载。 |

平衡输出接非平衡输入时，助手只提供冷端与屏蔽在输入端汇接这一种接法；必须由用户先确认两台设备手册明确允许。若不能确认，应停止施工并向设备厂家核实。助手不据接口类型推断冷端的电路功能，也不宣称所有设备都必须采用汇接。

## 无需选择的 21 种接法

平衡 LINE 接口（3 种输出 × 3 种输入）的九种组合均按功能对应：

| 输出 → 输入 | 逐线对应 |
| --- | --- |
| XLR → XLR | 2（+）→ 2；3（−）→ 3；1（屏蔽）→ 1 |
| XLR → 6.35 mm TRS | 2（+）→ T；3（−）→ R；1（屏蔽）→ S |
| XLR → 平衡端子 | 2（+）→ +；3（−）→ −；1（屏蔽）→ G |
| 6.35 mm TRS → XLR | T（+）→ 2；R（−）→ 3；S（屏蔽）→ 1 |
| 6.35 mm TRS → 6.35 mm TRS | T（+）→ T；R（−）→ R；S（屏蔽）→ S |
| 6.35 mm TRS → 平衡端子 | T（+）→ +；R（−）→ −；S（屏蔽）→ G |
| 平衡端子 → XLR | +→2；−→3；G（屏蔽）→1 |
| 平衡端子 → 6.35 mm TRS | +→T；−→R；G（屏蔽）→S |
| 平衡端子 → 平衡端子 | +→+；−→−；G→G |

这九种只适用于两端都已确认是平衡 LINE 输入/输出的设备。− 是信号冷端，其具体电路功能以设备为准；G 是屏蔽，不应默认短接两者。

非平衡 RCA/TS 单声道输出接平衡输入的六种组合，使用双芯屏蔽线：源信号接平衡输入 +；源回路的一根芯线接 −；屏蔽接 G。源端非平衡回路处将芯线和屏蔽汇接。仅用于已确认的 LINE 输出和 LINE 输入；关闭输入幻象或插孔馈电。该直连不自动补偿电平差，且源阻抗不平衡可能降低共模抑制。

| 输出 → 输入 | 逐线对应 |
| --- | --- |
| RCA → XLR | 中心针→2；源端回路芯线→3；屏蔽→1 |
| RCA → 6.35 mm TRS | 中心针→T；源端回路芯线→R；屏蔽→S |
| RCA → 平衡端子 | 中心针→+；源端回路芯线→−；屏蔽→G |
| TS → XLR | T→2；源端回路芯线→3；屏蔽→1 |
| TS → 6.35 mm TRS | T→T；源端回路芯线→R；屏蔽→S |
| TS → 平衡端子 | T→+；源端回路芯线→−；屏蔽→G |

剩余六种无需选择的方案是电脑/播放设备的 3.5 mm TRS 立体声 LINE 输出分接到双输入，以及 RCA/TS 单声道非平衡接口互接：

| 输出 → 输入 | 逐线对应 |
| --- | --- |
| 3.5 mm TRS → 双 RCA | T→左中心针（L）；R→右中心针（R）；S→左右外壳（公共回路分支） |
| 3.5 mm TRS → 双 TS | T→左 T（L）；R→右 T（R）；S→左右 S（公共回路分支） |
| RCA → RCA | 中心针→中心针（信号）；外壳→外壳（非平衡回路） |
| RCA → TS | 中心针→T（信号）；外壳→S（非平衡回路） |
| TS → RCA | T→中心针（信号）；S→外壳（非平衡回路） |
| TS → TS | T→T（信号）；S→S（非平衡回路） |

3.5 mm TRS 分接只适用于已确认的模拟立体声输出和双路线路输入；不适用于 TRRS 耳麦、麦克风输入或数字端口。T/R 分别送入双路输入的 L/R，左右信号保持独立，不得直接短接。接单声道输入的直连接法只取所选 L 或 R，可能遗漏另一声道内容；需要两边内容时，应先通过播放设备或混音器合成为单声道，再从单声道输出接入。这里说明的是信号处理边界，不表示本助手提供混音方案。RCA/TS 单声道输出只限 LINE 用途；被动乐器拾音器不是已确认的线路输出。

## 需选择后才显示的 46 种方案

平衡输出接单声道非平衡输入时，仅在确认手册允许后显示以下接法：

| 选择 | 连接 | 必须核实的条件 |
| --- | --- | --- |
| `coldReturn` 确认 | +→信号；−→非平衡回路；屏蔽→非平衡回路 | 两台设备说明书明确允许此线路，并允许冷端与屏蔽在输入侧汇接。 |

接双 RCA/TS 时，以上线路连接到所选的 L 或 R 侧；`both` 会把同一个平衡输出分支接到 L 和 R 两个独立输入，并将每根对应回路分别接入两侧。它不会短接平衡输出的两个声道，也不是混音；先核对两输入并联后的负载符合输出规格。只选一侧时，另一侧的信号和回路均保持未接。

3.5 mm TRS 立体声输出接单声道输入时，只取所选声道：L/T 或 R/R 接输入信号，另一信号输出保持未接。接平衡 LINE 输入时，TRS 的 S 公共回路用一根芯线接 −、屏蔽接 G，并在源端公共回路处汇接；接非平衡单声道输入时，S 接非平衡回路。不要将 L/R 输出直接并接。接平衡输入需关闭幻象或插孔馈电，不自动补偿电平差。

RCA/TS 单声道输出接双 RCA/TS 输入时，所选单侧连接信号和回路，另一侧均保持未接。`both` 表示一个低阻输出驱动两个独立高阻 LINE 输入，不是混音；核对输出允许的并联负载。RaneNote 109 明确区分一源分送多个输入与将多个输出直接相连或求和。

## 绘图约定

- XLR 图是线缆头视角。设备输出 XLR 公座通常配母线缆头，设备输入 XLR 母座通常配公线缆头；需以实际座口确认。定位标记朝上，插接面与焊接面按上述原厂图镜像。
- TRS/TS 插接视图按 T（尖端）、R（环）、S（套筒）标出接触功能。不同插头的内部焊片位置不通用，焊接时核对实物标记或厂家图。
- 平衡端子只按 +、−、G 的功能丝印绘制；不表示物理排列顺序。RCA 只按中心针和外壳功能绘制。
- 蓝、橙、灰、紫是图示网络颜色，不代表实际线芯颜色。端子接线以功能丝印和设备手册为准。
- 不按外形推断端口用途，不自动记录历史，不自动补偿 6 dB 或其他增益差。
