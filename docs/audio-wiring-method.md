# 接线助手的接法范围与依据

页面当前提供七类输出与七类物理输入，共 49 种可选组合。原有七类输出与八类输入、56 种组合及其历史记录身份保持不变；新增 3.5 mm 立体声输入后，底层模型共有七类输出与九类输入、63 种组合。RCA/TS 双头输入的 14 种组合仍用于兼容旧偏好和历史记录，不再单独显示为接口选项。读取旧偏好时，页面仅把 `rcaStereo`、`tsStereo` 分别显示为 RCA、TS 物理输入，实际接头数量依输出信号自动确定；读取时不改写偏好，既有记录的正文和偏好也不变。3.5 mm 立体声输入是单个接头，T/R/S 分别对应 L/R/G。场景名称只用于识别信号方向；外形相同不代表电平、平衡拓扑、接地设计或端口用途相同。施工前须核对两台设备的具体型号说明书。

## 模型状态与固定接法

底层模型中的七类输出和九类输入共 63 种组合均直接生成固定方案；当前页面可见的七类输出与七类输入共 49 种组合也都可直接使用。页面没有冷端、声道或负载确认步骤。模型只对未知或非字符串接口 ID 返回 unsupported；已知组合始终为 ready，可显示、复制和导出其固定接法。

| 接口组合 | 固定路由 | 施工前核对 |
| --- | --- | --- |
| 平衡输出 → 非平衡输入 | + 接信号；− 芯线和屏蔽分别到输入回路，并仅在输入端汇接。 | 两台设备说明书明确允许该冷端接法。 |
| 平衡或单声道输出 → 双 RCA/TS 输入 | 单个信号与回路分送到 L/R 两个独立输入；平衡输出的冷端与屏蔽分别接两侧回路。 | 两路输入是独立高阻 LINE 输入，并核对并联负载；平衡输出还需核对手册允许输入端汇接。 |
| 3.5 mm TRS 立体声输出 → 单声道输入类型 | T（L）和 R 分别接入两个独立单声道输入；S 分别接两头回路。 | 保留 L/R，不得将两个输出并接；两路接平衡输入时，仍是非平衡源信号。 |

### 新增的 6.35 mm 大三芯 TRS 立体声方案

6.35 mm 接头在选择器中明确区分三种用途：大二芯 TS 是单声道非平衡信号/G；大三芯 TRS 平衡是单声道 +/−/G；大三芯 TRS 立体声是双声道 L/R/G。平衡与立体声使用不同接口 ID，不从外形推断用途。

新增 14 种组合由 6 个既有输出接入 6.35 mm 立体声输入，以及 6.35 mm 立体声输出接入 8 种输入构成：

| 组合 | 固定路由 |
| --- | --- |
| 平衡单声道输出 → 6.35 mm 立体声输入 | + 分送到 T（L）和 R（R）；− 与屏蔽分别接到输入 S（G），仅在输入端汇接。 |
| 非平衡单声道输出 → 6.35 mm 立体声输入 | 信号分送到 T（L）和 R（R）；回路接 S（G）。 |
| 3.5 mm 或 6.35 mm 立体声输出 → 6.35 mm 立体声输入 | T→T（L）；R→R（R）；S→S（G），保持两声道。 |
| 6.35 mm 立体声输出 → 单声道接口类型 | T（L）与 R（R）分别接到两个独立单声道输入；S 分别接各头回路。双平衡头各自使用 +/−/G。 |
| 6.35 mm 立体声输出 → 双 RCA/TS 输入 | T、R 分别送到 L/R；S 分送到两个回路。 |

这些固定方案不是混音，也不会把非平衡信号转换为平衡信号。连接平衡输入、冷端汇接或并联多个输入时，仍须核对具体设备手册及 LINE 输入负载。

### 新增的 3.5 mm 立体声输入方案

3.5 mm 立体声输入是单个接头，T/R/S 分别对应 L/R/G。本轮新增的七种输出组合不改变原有 56 种模型或历史记录：

| 输出 → 输入 | 固定路由 |
| --- | --- |
| 3.5 mm 或 6.35 mm 立体声输出 → 3.5 mm 立体声输入 | T→T（L）；R→R（R）；S→S（G），保持两声道。 |
| 平衡单声道输出 → 3.5 mm 立体声输入 | + 分接到 T（L）和 R（R）；− 与屏蔽分别接到输入 S（G），仅在输入端汇接。 |
| 非平衡单声道输出 → 3.5 mm 立体声输入 | 信号分送到 T（L）和 R（R）；回路接 S（G）。 |

立体声输出直接接入时保留 L/R。平衡或单声道输出分接到该输入时，共用输入端 S 回路；仍须按设备说明书核对输入用途及冷端接法。

这些是应用按接口组合采用的固定布线方案，不表示设备已通过电气检测或用户已确认兼容。外形不能证明接口用途；施工前仍须核对设备型号说明书。偏好与历史记录中的 sourceChannel: "both"、outputMode: "coldReturn"、destinationChannel: "both" 表示固定方案的记录身份，不是确认凭据；旧的 sourceChannel: "left"/"right" 或单侧目标值不能改变新固定路由，也不会与新双头方案合并。
## 原有 42 种接法：基础对应的 26 种

平衡 LINE 接口（3 种输出 × 3 种输入）的九种组合均按功能对应：

| 输出 → 输入 | 逐线对应 |
| --- | --- |
| XLR → XLR | 2（+）→ 2；3（−）→ 3；1（屏蔽）→ 1 |
| XLR → 6.35 mm TRS | 2（+）→ T；3（−）→ R；1（屏蔽）→ S |
| XLR → 平衡端子 | 2（+）→ +；3（−）→ −；1（屏蔽）→ G |
| 6.35 mm TRS → XLR | T（+）→ 2；R（−）→ 3；S（屏蔽）→ 1 |
| 6.35 mm TRS → 6.35 mm TRS | T（+）→ T；R（−）→ R；S（屏蔽）→ S |
| 6.35 mm TRS → 平衡端子 | T（+）→ +；R（−）→ −；S（屏蔽）→ G |
| 平衡端子 → XLR | +→2；−→3；G（屏蔽）→1 |
| 平衡端子 → 6.35 mm TRS | +→T；−→R；G（屏蔽）→S |
| 平衡端子 → 平衡端子 | +→+；−→−；G→G |

这九种只适用于两端都已确认是平衡 LINE 输入/输出的设备。− 是信号冷端，其具体电路功能以设备为准；G 是屏蔽，不应默认短接两者。

非平衡 RCA/TS 单声道输出接平衡输入的六种组合，使用双芯屏蔽线：源信号接平衡输入 +；源回路的一根芯线接 −；屏蔽接 G。源端非平衡回路处将芯线和屏蔽汇接。仅用于已确认的 LINE 输出和 LINE 输入；关闭输入幻象或插孔馈电。该直连不自动补偿电平差，且源阻抗不平衡可能降低共模抑制。

| 输出 → 输入 | 逐线对应 |
| --- | --- |
| RCA → XLR | 中心针→2；源端回路芯线→3；屏蔽→1 |
| RCA → 6.35 mm TRS | 中心针→T；源端回路芯线→R；屏蔽→S |
| RCA → 平衡端子 | 中心针→+；源端回路芯线→−；屏蔽→G |
| TS → XLR | T→2；源端回路芯线→3；屏蔽→1 |
| TS → 6.35 mm TRS | T→T；源端回路芯线→R；屏蔽→S |
| TS → 平衡端子 | T→+；源端回路芯线→−；屏蔽→G |

3.5 mm TRS 立体声输出接单声道输入类型时，五种方案都保留 T（L）和 R 两个声道，分别接到两个独立单声道接头：

| 输出 → 输入 | 逐线对应 |
| --- | --- |
| 3.5 mm TRS → 双路 XLR | T（L）→ L 头 2（+）；R→ R 头 2（+）；S 分别接两头 3（−）与 1（屏蔽） |
| 3.5 mm TRS → 双路 6.35 mm TRS | T（L）→ L 头 T（+）；R→ R 头 T（+）；S 分别接两头 R（−）与 S（屏蔽） |
| 3.5 mm TRS → 双路平衡端子 | T（L）→ L 头 +；R→ R 头 +；S 分别接两头 − 与 G |
| 3.5 mm TRS → 双 RCA | T（L）→ L 中心针；R→ R 中心针；S 分别接两头外壳 |
| 3.5 mm TRS → 双 TS | T（L）→ L 头 T；R→ R 头 T；S 分别接两头 S |

L 头的 + 接 T（L），R 头的 + 接 R；各头的 − 与 G 接源端 S。L/R 不会接到同一个头的 +/−，非平衡源也不会因此成为平衡信号。端子按两组 +/−/G 功能接线，实际丝印顺序以设备为准。

剩余六种无需选择的方案是 3.5 mm TRS 立体声 LINE 输出分接到双输入，以及 RCA/TS 单声道非平衡接口互接：

| 输出 → 输入 | 逐线对应 |
| --- | --- |
| 3.5 mm TRS → 双 RCA | T→左中心针（L）；R→右中心针（R）；S→左右外壳（公共回路分支） |
| 3.5 mm TRS → 双 TS | T→左 T（L）；R→右 T（R）；S→左右 S（公共回路分支） |
| RCA → RCA | 中心针→中心针（信号）；外壳→外壳（非平衡回路） |
| RCA → TS | 中心针→T（信号）；外壳→S（非平衡回路） |
| TS → RCA | T→中心针（信号）；S→外壳（非平衡回路） |
| TS → TS | T→T（信号）；S→S（非平衡回路） |

3.5 mm TRS 分接只适用于已确认的模拟立体声输出和 LINE 输入；不适用于 TRRS 耳麦、麦克风输入或数字端口。接双 RCA/TS 输入时，T/R 分别送到 L/R；接单声道接口类型时，仍使用两个独立接头保留 L/R。左右信号保持独立，不得直接短接。连接平衡输入时，每路仍是非平衡源信号。RCA/TS 单声道输出只限 LINE 用途；被动乐器拾音器不是已确认的线路输出。

## 原有 42 种接法：固定规则覆盖的 16 种方案

这些方案同样直接显示，没有应用内确认门槛。表中接头针位与导线网络由固定规则确定；表述中的说明书和负载检查是施工前的实际设备核对。

平衡输出接单声道非平衡输入时，固定只采用输入端汇接：

| 输出 → 输入 | 固定逐线对应 |
| --- | --- |
| XLR → RCA/TS | 2（+）→信号；3（−）→非平衡回路；1（屏蔽）→非平衡回路 |
| 6.35 mm TRS → RCA/TS | T（+）→信号；R（−）→非平衡回路；S（屏蔽）→非平衡回路 |
| 平衡端子 → RCA/TS | +→信号；−→非平衡回路；G（屏蔽）→非平衡回路 |

冷端芯线和屏蔽在图中分别到达输入回路端子；只在输入端汇接。仅当两台设备说明书明确允许这一具体接法时施工；不能确认时，应停止施工并向设备厂家核实。助手不据接口类型推断冷端的电路功能，也不宣称所有设备都适用汇接。

平衡输出接双 RCA/TS 时，固定将同一个平衡输出分送到 L 和 R 两个独立输入，并将每根对应回路分别接入两侧。它不会短接平衡输出的两个声道，也不是混音。先核对两个输入均为独立高阻 LINE 输入，并确认并联负载符合输出规格。

单声道 RCA/TS 输出接双 RCA/TS 时，同样固定 1 分 2 到 L/R，不提供单侧目标选项。destinationChannel: "both" 只描述这条固定线路，不记录用户确认。RaneNote 109 明确区分一源分送多个输入与将多个输出直接相连或求和。

3.5 mm TRS 立体声输出接单声道接口类型时，按上表使用两个相同类型的输入接头：T（L）连接 L 头信号，R 连接 R 头信号；S 分别连接两头的回路，平衡输入时也分别接各头 − 与 G。接平衡输入需关闭幻象或插孔馈电，不自动补偿电平差。不要将 L/R 输出直接并接。

## 绘图约定

- XLR 图是线缆头视角。设备输出 XLR 公座通常配母线缆头，设备输入 XLR 母座通常配公线缆头；需以实际座口确认。定位标记朝上，插接面与焊接面按上述原厂图镜像。
- TRS/TS 插接视图按 T（尖端）、R（环）、S（套筒）标出接触功能。不同插头的内部焊片位置不通用，焊接时核对实物标记或厂家图。
- 平衡端子只按 +、−、G 的功能丝印绘制；不表示物理排列顺序。RCA 只按中心针和外壳功能绘制。
- 蓝、橙、灰、紫是图示网络颜色，不代表实际线芯颜色。端子接线以功能丝印和设备手册为准。
- 不按外形推断端口用途，不自动补偿 6 dB 或其他增益差。

## 页面首次使用与本机偏好

页面初次打开时以 XLR 平衡输出 → 平衡端子作为默认示例。用户可查看图、复制或导出示例；示例状态会加在复制内容和导出图前。接口卡以接头类型和信号用途为主，设备类别只作常见示例；具体型号用途仍以设备说明书为准。

页面沿用版本 1 偏好字段保存接口 ID、两端是否由用户选择以及旧视角字段；当前页面始终显示焊接端连线图，旧视角字段不控制显示。重置会清空两端接口并持久保存空偏好。重新进入时恢复接口偏好并提醒核对本次设备；页面按接口组合重新生成固定方案，历史偏好不会改变接法，也不会替代设备手册与负载核对。页面不保存接线结果、复制内容或针脚方案。默认示例或刚恢复的接口会在导出图中带核对提示。

方案记录身份中的 sourceChannel: "both" 表示固定保留 T（L）与 R 两声道，不是页面选项；outputMode: "coldReturn" 和 destinationChannel: "both" 分别表示固定冷端汇接与固定 1 分 2 路由，不表示用户已经确认设备条件。旧的 left/right、缺少声道字段或仅选一侧的记录不匹配新的双头方案；打开历史记录时按接口组合重建当前接法，原记录正文与偏好保持原样。
