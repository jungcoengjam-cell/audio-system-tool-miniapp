# 音频线默认规格

按用户要求，新建单条和批量添加的音频线默认填写 **RVPE 2×0.5 mm²**，平衡/非平衡音频线均不再展示 0.3、0.5 快捷选择。规格输入框仍可手动填写；扬声器线原有 RVV 规格选项保持。

只有尚未手改的新建草稿会自动跟随类型：切换到扬声器线或自定义线材时清空自动填入的 RVPE，切回音频线时恢复默认。手动填写或主动清空后保留用户输入。编辑、复制已有线路保留原规格，包括空值、0.3 及自定义内容；不迁移历史数据。
