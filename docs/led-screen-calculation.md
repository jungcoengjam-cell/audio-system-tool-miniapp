# LED 大屏尺寸预估

## 适用范围

本模块用于规则矩形墙面上的 LED 大屏前期尺寸预估。结果只解决屏体物理尺寸、整数拼装数量、墙面余量、标称点间距与观看距离的初步匹配，不替代钢结构、供配电、控制系统和安装深化。

## 输入

- 墙体宽度与高度，单位 m。
- 上方与下方最低预留空间，单位 m。
- 四周包边宽度，默认每边 5 cm，可按项目实际调整。
- 目标画面比例：16:9、4:3、21:9、16:10 或 32:9。
- 拼装单元：
  - 模组：320 × 160 mm。
  - 常规箱体：640 × 480 mm。
  - 高端 A 系列箱体：600 × 337.5 mm。
- 最近观看距离，单位 m。
- 点间距：系统推荐或指定公司常规规格 P1.25、P1.53、P1.86、P2.0；特作规格不进入常规推荐。

上方预留、下方预留和包边输入留空或只含空格时视为未完成输入；明确填写 `0`（包括 `0`、`'0'` 或带空格的 `' 0 '`）仍是有效的零值。省略包边字段时继续使用每边 `0.05 m` 的默认值，负值仍按原有非负校验提示。

## 尺寸枚举

屏体只能由完整模组或箱体拼装：

```text
屏体宽度 = 横向数量 × 单元宽度
屏体高度 = 纵向数量 × 单元高度
```

当前整数拼装得到的是净屏尺寸。候选组合必须先从墙面范围中扣除四周包边，且不得超过扣除上下预留与包边后的可用高度。算法先筛选与目标画面比例误差不超过 5% 的整数拼接方案，再从中选择净屏面积最大的方案；若没有候选方案满足 5% 条件，则选择比例误差最小、面积更大的方案。由于模组或箱体必须整数拼接，实际比例可能与目标比例存在小幅偏差。

```text
含包边安装外宽 = 净屏宽度 + 2 × 单边包边宽度
含包边安装外高 = 净屏高度 + 2 × 单边包边宽度
```

屏体默认水平居中。整数拼装后剩余的可用高度平均分配到屏体上下，因此用户填写的上、下预留均被视为最低预留值：

```text
左右余量 = (墙体宽度 - 含包边安装外宽) ÷ 2
额外纵向余量 = 墙体高度 - 上预留 - 下预留 - 含包边安装外高
实际上余量 = 上预留 + 额外纵向余量 ÷ 2
实际下余量 = 下预留 + 额外纵向余量 ÷ 2
```

## 点间距与观看距离

系统推荐只从公司现有的四种常规点间距中选择。推荐规则取满足 `最近观看距离 ≥ 1.7 × 点间距` 的最大现有点间距；若没有规格满足，则返回最细的 P1.25 并提示观看位置偏近。

指定点间距时不替换用户选择，只进行观看距离校核：

- 最近观看距离小于点间距数值对应的米数：距离过近。
- 位于 `P～1.7P m`：可以观看，但位置偏近。
- 位于 `1.7P～3P m`：观看距离匹配。
- 大于 `3P m`：当前点间距清晰度富余。

上述距离是前期选型参考，不是验收标准。实际清晰度还会受到信号分辨率、显示内容、亮度、对比度和观看者视力影响。

## 分辨率

初版按屏体实际物理尺寸除以标称点间距计算估算分辨率，并取最接近的整数像素。P1.53、P1.86 等名称可能是标称值；未录入厂家准确像素矩阵前，页面必须明确显示为“估算分辨率”。

## 结果长图

LED 页面可把当前有效输入、推荐净屏、安装外尺寸、拼装数量、估算分辨率、观看距离校核和按实际比例绘制的墙面示意图生成一张高清 PNG。图片完全在小程序本地 Canvas 中绘制，不上传云端，也不写入项目记录。

- “转发图片”必须由用户主动点击，支持直接调起微信图片转发；低版本微信不支持时退回原图预览，用户可长按处理。
- “保存到相册”只在用户主动点击后调用相册写入能力；首次使用可能需要用户授权。上传正式版前，应在小程序管理后台的用户隐私保护指引中核对“保存图片到相册”的使用说明。
- 修改任一输入或选项后，已经生成的旧图片立即失效，避免把上一版方案误发给现场人员。
