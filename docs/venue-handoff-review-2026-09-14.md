# 补声传播复核交接方法

日期：2026-09-14

本文定义会议室报告/培训型布局中新增的“补声传播复核”显示依据。当前实现已完成；版本号保持 `5.0.0`，本轮改动尚未发布。它是现有布局计划的复核摘要，不改变原有布局、补声数量、型号、级别、颜色或声级数据，也不把几何参考转换成 DSP 延时结论。

## 目的与范围

复核在结果级复用既有源位置、源姿态和 `aimDepth` 参考排数据，只检查听音区横向的 `1/4`、`1/2`、`3/4` 三个点。轻量复核不因展开动作必然构建完整 plan；完整 plan 仍附同样的 `handoffReview`，供布局展开按需使用。

每个点先在共同的标称 H/V 几何包络内找参考源，再比较声传播声程：

- 当前级：当前补声源；
- 前级：主扩与更靠前的补声源集合，不包含当前补声及其后的补声；
- 对每一类分别选共同包络内三维声程最近的参考源，并记录源标签；
- 只有两类都有共同几何范围时才输出该点的 `deltaMs`；没有补声时不显示本复核。

“共同标称 H/V 包络”只表示该点同时落在待比较源的既有名义水平/垂直几何参考范围内。它不是实测有效覆盖、实际主导声源或等电平位置的判定，也不把 `coverageEndDepth` 的责任分界当作声传播截止。

## 符号与计算

对横向点 `p ∈ {1/4, 1/2, 3/4}`，记：

```text
d_front(p) = 前级参考源到 p 的三维欧氏声程（m）
d_fill(p)  = 当前补声参考源到 p 的三维欧氏声程（m）
deltaMs(p) = (d_front(p) - d_fill(p)) / 343 × 1000（ms）
```

符号解释：

- `deltaMs > 0`：按固定声速的几何声程，补声先到；
- `deltaMs < 0`：按固定声速的几何声程，补声后到；
- `deltaMs = 0`：两条参考声程相同，不能据此宣称已完成同步。

`343 m/s` 是本轮固定参考假设，不提供温度输入。它只把两条几何声程差换算成声传播时间差；Yamaha 的 Audio Quality 说明将声传播时延与 A/D、网络、DSP、D/A 等处理器时延分列，说明只算声程不是总到达时间：[Audio Quality—table 502](https://usa.yamaha.com/products/contents/proaudio/docs/audio_quality/05_audio_quality.html)。

Meyer Sound Galileo GALAXY 用户指南的 Product integration example 用产品相位曲线和等电平覆盖位置说明系统对齐流程；其 Summing Matrix 也指出整条通路的处理器延迟需要测量。该页面是 Meyer 产品集成示例，不是会议室布置通则：[Galileo GALAXY 用户指南](https://docs.meyersound.com/products/en/user-guide---galileo-galaxy.html)。因此本复核不自动生成 DSP 延时、电平、相位或电子处理延时结论。

## 展开依据与结果摘要

页面详情和结果图长图摘要使用轻量复核缓存，并补充以下最小字段；展开布局图或复制完整结果时，沿用原有按需构建/复用完整 plan 的流程：

| 字段 | 含义 |
| --- | --- |
| 横向点 | `1/4`、`1/2`、`3/4` |
| plan 保留字段 | 继续保留 raw 参考排深度、源位置、姿态及三维声程；不改写原布局 plan |
| 页面展示 | 展示当前补声/前级参考源标签、位置和传播差，不把 raw 声程扩展成新的布局或声级字段 |
| `deltaMs` | 按 `343 m/s` 得出的几何声传播差；无共同范围时留空 |
| 结果图摘要 | 只压缩展示复核摘要，保留源标签/位置/传播差的可读信息 |
| 复制文字 | 包含 `1/4`、`1/2`、`3/4` 三点详情及不可比较点说明 |
| 共同包络 | 是否存在共同标称 H/V 几何范围 |
| 复核限制 | 说明这不是实际主导声源、等电平位置或系统总到达时间 |

完整 plan 继续保留 raw 三维声程和既有布局字段；页面详情只展示源标签、位置和传播差，结果图压缩为摘要，复制文字保留三个横向点的详情。原有布局坐标、补声距离、型号、数量、级别、颜色和声级数字保持原样。没有补声时隐藏该区块，不用“0 ms”或空结果制造复核结论。

## 可验收的计算样例

以下是公式 fixture，用于补充说明符号、源标签和边界行为；实际审计案例见下一节。

| 样例 | 当前补声 `d_fill` | 前级最近源 `d_front` | 共同包络 | 预期复核值 |
| --- | ---: | ---: | --- | --- |
| A：补声声程更短 | 8.00 m（F2） | 11.43 m（M1） | 有 | `+(11.43−8.00)/343×1000 ≈ +10.00 ms`，记录 M1/F2 |
| B：补声声程更长 | 8.00 m（F2） | 7.50 m（F1） | 有 | `+(7.50−8.00)/343×1000 ≈ −1.46 ms`，记录 F1/F2 |
| C：不可比较 | 8.00 m（F2） | — | 无 | 不给 `deltaMs`，保留无共同几何范围原因 |

显示边界：没有当前补声时整个复核区块不显示；复制文字保留三个横向点的详情，结果图只保留压缩摘要。

## 已取得的实际案例

以下数值来自 `docs/verification/venue-handoff-2026-09-14/independent-check.cjs` 使用的真实计算输入与 plan 输出，以及 `visual-qa.cjs` 写入的 `calculated-cases.json`；案例 B 使用后者，`independent-check.json` 汇总独立核对覆盖范围。它们是回归案例，不是现场声学结论。

### 案例 A：默认短边前置，第一组补声有一个不可比较点

输入：`12 × 8 × 4 m`，短边前置，首排 `3 m`，末排 `11 m`，听音宽 `7 m`，会议二级目标。

第一组补声参考排 raw 深度为 `9.4642605319 m`，安装 raw 深度为 `6.3927815958 m`。`1/4` 点记录 `M1 → F1`，前级声程 `9.5531265781 m`，当前补声声程 `3.6368231817 m`，`deltaMs = +17.2486979486 ms`；`1/2` 点无共同几何范围，参考源标签、声程与毫秒值留空；`3/4` 点记录 `M2 → F2`，同样为 `+17.2486979486 ms`。该案例显示不可比较点不会被强行补成 `0 ms`。

### 案例 B：visual-qa 双组输入以前一组补声作为前级参考

输入：`12 × 4 × 4 m`，短边前置，首排 `0.5 m`，末排 `11 m`，听音宽 `1 m`，会议二级目标；对应 `calculated-cases.json` 的 `report-two-fill-groups` 案例。

第一组补声安装 raw 深度为 `2.4562734190 m`，参考排 raw 深度为 `4.4123897008 m`，三个点均可比较；`1/4` 为 `M1 → F1`、`deltaMs = +5.5127476 ms`，`1/2` 为 `M1 → F1`、`+5.1451913 ms`，`3/4` 为 `M2 → F2`、`+5.5127476 ms`。第二组补声安装 raw 深度为 `5.3904478417 m`，参考排 raw 深度为 `9.1301492806 m`，三个点均有共同几何范围，前级源来自第一组补声：`1/4` 为 `F1 → F3`，`deltaMs = +8.0145497 ms`；`1/2` 为 `F1 → F3`，`+7.9146920 ms`；`3/4` 为 `F2 → F4`，`+8.0145497 ms`。这确认前级集合包含主扩和更靠前补声，并按共同包络内最近声程选择源标签；双组摘要也可与结果图对照。

独立检查覆盖 `43` 个有效场景、`5` 个既有输入校验拒绝、`46` 组补声、`138` 个横向点、`51` 个不可比较点和 `21` 个前组补声参考；既有 plan 字段与 renderer fixture 保持不变。页面控制器证据另记录了折叠时延迟构建、导出缓存复用、输入变更清空旧图、无补声/模式切换清空详情、过期导出不回写和外部结果使用自身 plan；完整最终证据见下方审计记录。

## 适用限制

- 参考排、源姿态和 `aimDepth` 来自现有几何计划；本方法不重新选择布局，不重新计算产品数据或声级。
- 共同包络是名义几何条件，不代表频段极坐标、房间反射、遮挡、干涉、等电平交接或实际主导声源。
- `deltaMs` 只包含声传播声程差；真正 DSP 延时、电平、相位和电子处理延时必须在实际安装后用系统配置和现场测量确定。
- 343 m/s 为固定参考假设，没有温度、湿度或气流输入；现场声速变化和设备链路延时不由此自动补偿。
- `coverageVerification` 仍按现有边界保持未验证；本复核不能替代专业预测软件或多点现场声学测量。
