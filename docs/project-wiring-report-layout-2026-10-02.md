# 项目布线线路明细导出排版

本轮只重排“线路明细”报告图片。每条线路改为独立卡片，分别呈现线号、用途、状态、起点和终点设备/端口/线缆侧端头，并将线材、长度、规格与备注分开排版。短英文端口和型号尽量保持完整；过长内容按字段宽度换行，超高线路使用带线号的续页卡片。页面宽度仍为 720 逻辑像素，单页高度控制在 1500 逻辑像素内。

改动限于 `pages/project-wiring/report.js`、`tests/project-wiring-report-test.js` 和本说明。线路报告的页数会按新的卡片布局和续页规则重新计算，分页结果仍通过既有 `pages` 接口返回；文本、线路数、类型和冻结输出接口保持不变。材料与线号标签报告沿用原分页和绘制分支。没有修改核心算法、产品数据、项目记录或存储语义。
