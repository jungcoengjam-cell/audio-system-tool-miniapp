# 布线型号与规格快捷录入

根据用户提出的 RVPE 录入需求，“通道与线缆”的单条新增、编辑和批量添加将“规格”改为“型号与规格”，字段独占一行，支持手动填写完整型号及芯数、截面积。

快捷项按当前线材类型显示：

| 线材类型 | 可点选的完整规格 |
| --- | --- |
| 平衡、非平衡音频线 | RVPE 2×0.3 mm²、RVPE 2×0.5 mm² |
| 扬声器线 | RVV 2×1.5 mm²、RVV 2×2.5 mm² |
| 自定义线材 | 自由填写 |

点选后可以继续修改。新建不自动填写规格；切换线材类型只更新快捷项与输入示例，不覆盖已输入文字。编辑、复制沿用旧规格，取消不写入。批量修改规格会使旧预览失效，重新预览后才允许确认添加。

本轮是录入辅助，不做线径计算或自动选型。完整文本仍保存在原有 `spec` 字段；线路、材料汇总、复制清单和导出报告沿用该字段，材料按原有规则区分不同规格。没有改动存储结构、历史数据、计算算法、产品资料或前一轮弹层滚动修复。

型号依据：用户指定 RVPE；[原始采购明细](https://www.ccgp-neimenggu.gov.cn/gpx-bid-file/2023/9/28/402881cc8aa8c7b6018adaee82731ac9.pdf?accessCode=a772660f7796433ce4111da19d10cf15) 明确列出 RVPE 2×0.3、RVPE 2×0.5 和 RVV 2×1.5，[制造商 RVV 规格表](https://www.gecable.com/rvv-cable/) 列有 2×1.5、2×2.5。这里只据此提供录入示例，不表示这些规格适用于所有现场。

修改文件为 `pages/project-wiring/index.js`、`pages/project-wiring/index.wxml`、`tests/project-wiring-page-test.js`。复用原有输入框及快捷按钮样式，没有新增样式或依赖。`tests/release-check.js` 的内部总量预算更新为 2026 KiB、WXML 为 239 KiB，其余门禁不变；有效包 2,073,847 字节，比本轮前增加 1,840 字节。
