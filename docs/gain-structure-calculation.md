# 系统增益结构助手计算规则

本文档记录 2.0.7 系统增益结构助手的计算核心。当前版本只计算 DSP 模拟输出与功放输入级的匹配关系，不控制设备，也不替代现场电压、削波和噪声测量。

## 1. 已知基准

项目当前 DSP 模拟输出标定：

```text
0 dBFS = +18.4 dBu
0 dBu = 0.775 V RMS
```

当前值采用本次实测设备的校准条件，原始条件与验证边界见 [`docs/calculation.md`](calculation.md)；它不是所有处理器通用的固定值。

所以：

```text
DSP_output_dBu = DSP_level_dBFS + 18.4
```

## 2. 功放满功率输入电平

### 2.1 说明书提供输入灵敏度

功放档位为 V 时：

```text
Amp_full_input_dBu = 20 × log10(V_sensitivity / 0.775)
```

功放档位直接以 dBu 标注时，采用说明书数值，不重复换算。

### 2.2 说明书只提供可选电压增益

先从当前功放模式和负载阻抗对应的说明书功率表取额定功率：

```text
V_amp_output = √(P_amp_rated × Z_load)
V_amp_input = V_amp_output / 10^(Gain_dB / 20)
Amp_full_input_dBu = 20 × log10(V_amp_input / 0.775)
```

只使用说明书明确给出的阻抗功率点，不做插值。

## 3. DSP 目标峰值

第一版默认把 DSP 节目峰值目标设为：

```text
-6 dBFS = +12.4 dBu
```

保留 6 dB 数字输出余量，便于吸收现场标定误差和偶发峰值。这是本工具的初始调试建议，不是国家标准或所有系统的固定值。

## 4. 系统对齐衰减建议

当 DSP 目标峰值高于功放满功率输入电平：

```text
Attenuation_dB = DSP_target_dBu - Amp_full_input_dBu
```

该数值表示 DSP 模拟输出到功放功率级之间所需的总对齐衰减，不等同于某一个固定旋钮位置。只能选择一个位置执行：

1. **DSP 最终输出增益（默认推荐）**：功放输入电平控制保持 0 dB 衰减或等效单位增益，DSP 最终输出增益设置为 `-Attenuation_dB`。应优先放在限幅器之后的最终输出环节，便于锁定、复制和复核。
2. **功放输入电平/衰减控制**：DSP 最终输出保持 0 dB，功放从 0 dB 衰减位置回退 `Attenuation_dB`。仅适用于面板、屏幕或软件提供可靠 dB 数值，或现场能够实测的情况。

两处不得重复施加相同衰减。功放旋钮没有 dB 刻度时，不输出钟点位置或格数推测。

如果结果小于 0，表示当前 DSP 目标峰值不足以把功放推到额定输出。此时输出“驱动余量不足”，不提供负衰减；应改用更高灵敏度/更高电压增益档位，或重新选择 DSP 峰值目标。

## 5. 节目动态余量

会议语音初始值采用：

```text
Program_headroom = 12 dB
Nominal_DSP_level = Target_peak_dBFS - Program_headroom
```

在默认条件下：

```text
Target_peak = -6 dBFS
Nominal_DSP_level = -18 dBFS
```

12 dB 适合作为会议语音的初始余量。现场如果包含未压缩音乐、强瞬态信号或用途不确定，应提高节目动态余量，不能把 12 dB 当成所有节目类型的统一标准。

## 6. 输出结果

计算模块输出：

- 功放额定输出所需输入电压与 dBu。
- 功放不衰减时对应的 DSP dBFS。
- 推荐系统对齐衰减及其执行位置。
- DSP 目标峰值与标称工作电平。
- DSP 输入电平表目标、DSP 最终输出增益与功放输入电平控制设置。
- 功放输入连接器标称电平、衰减后的等效电平及可用动态余量。
- 无法达到额定输出时的驱动差额。
- 计算依据是厂家输入灵敏度，还是额定功率与电压增益反算。

## 7. 现场校准边界

- 功放输入电平控制没有精确 dB 数值时，推荐衰减量只能作为目标值，必须用测试信号和电压/削波状态复核；“衰减后等效电平”不等同于输入连接器处实测电压。
- DSP 输入增益没有跨系统固定数值；应调整上游或输入增益，使正常节目平均值接近所选标称工作电平、峰值接近目标峰值，同时避免输入 ADC 削波。
- 选择功放输入电平控制执行衰减时，还需确认功放输入级最大允许电平，不能只看满功率输入灵敏度。
- 设备标称值、供电电压、负载阻抗和限幅保护会带来误差。
- 本模块只建立电子增益结构；声反馈前增益、房间均匀度和最终听音声压仍需现场测量。
- 功放输入档位未在说明书注明默认值时，必须由用户核对现场拨码或屏幕设置。

## 8. 参考依据

- Biamp《Gain structure》：说明信噪比、动态范围和 Headroom 的关系，并指出语音与音乐所需余量不同。
- Biamp《Gain structure: input and output levels》：说明应按设备实际 0 dBFS 对应模拟电平，并匹配前级输出电压与后级输入灵敏度。
- Biamp《Setting amplifier gain for optimal sound levels》：说明固定安装可将功放衰减保持在 0 dB，并在 DSP 输出端完成衰减，以降低被误改的风险。
- QSC《PowerLight 2A User Manual》：明确区分固定输入灵敏度与固定电压增益，并说明输入灵敏度是使功放达到额定输出所需的输入电压。
