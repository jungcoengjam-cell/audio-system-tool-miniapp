当前产品参数来自用户提供的公司产品说明书 PDF。核心计算字段记录在 `data/equipment.js`，资料库补充规格记录在 `data/speaker-specifications.js`、`data/cameras.js` 与 `data/stage-lighting.js`。

截至 2026-08-01，已复核：

- 功放：38 个型号
- 音箱：148 个实际型号
- 摄像机：26 个型号
- 舞台灯光设备：149 个型号（灯光控台/控制类 16、灯具 123、电源直通箱/电力控制类 10）

详细导入记录见 `docs/data-import-2026-07-09.md`。

录入原则：

## 音箱数据来源

资料来源：

```text

```

录入原则：

- 录入能确认额定功率、标称阻抗、频率下限的低阻无源音箱。
- 声压级模块额外录入说明书明确给出的灵敏度，单位为 `dB @ 1W/1m`。
- 排除空 PDF、扫描件、字段不足、异常阻抗、定压或当前计算器不适用的资料。

## 舞台灯光数据来源

资料来源：

```text
C:\Users\wxx\Desktop\H01-舞台灯光
```

录入原则：

- 同型号存在多份说明书时，优先采用版本日期较新且内容完整的文件。
- 灯具自动编址只使用说明书明确列出的 DMX 通道模式，不根据通道表猜测不存在的模式。
- 121 款灯具已确认 DMX 通道模式，可从编址页面搜索并自动带入。
- `TL-SL622` 与 `TL-SL643` 的说明书分别标注手动、有线/无线控制，不进入 DMX 自动编址，但仍保留在资料库中。
- 灯光控台、网络/信号控制设备和电源直通箱当前作为资料查阅，不参与灯具地址计算。

## 数据使用原则

- 只使用说明书明确给出的功率和阻抗数据。
- 未给出功率的负载点不插值、不猜测。
- 如果用户选择的总阻抗没有对应功放功率数据，小程序显示“暂时无法计算”。
- 声压级模块不接受手动灵敏度；未确认整箱灵敏度的型号不参与声压级估算。
