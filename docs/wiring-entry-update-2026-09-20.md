# 通道与线缆入口更新 · 2026-09-20

状态：本地实现与独立复审完成，本次改动未上传发布。正式版本仍为 `5.0.1`。

## 使用路径

- 工具 → 音频 → **通道与线缆**。它与接线助手相邻，位于音频横向卡片的前两位；接线助手仍打开原来的接法查询页面。
- 项目 → 对应现场项目卡上的 **布线**。项目页首次打开默认展示现场项目，常用收藏仍可切换查看；返回页面时保留用户已经选择的标签。
- 项目详情保留 **通道与线缆** 入口。项目卡新增 **报告** 按钮，直接进入原有项目详情。

工具入口有当前项目时直接打开该项目；没有当前项目时，在本页底部选择或新建项目。页面上方显示正在查看的项目，并提供切换操作。取消选择后，原项目内容保留；首次未选项目时仍有明确的选择入口。

普通选择只切换本页打开的项目，不改变其他计算工具所使用的全局当前项目。新建沿用原有 `createProject` 行为，创建后成为当前项目并直接打开线路表。保存始终按本页明确的项目 ID 执行。

## 界面和边界

沿用图上字下的小卡片尺寸，新入口使用独立的端点与线路图形，不复用接线助手图片。项目卡显示线路数量，并提供等宽等高的布线、报告按钮；主要按钮使用填色、统一字体和 10px 间距。

项目选择列表不展示内部编号，长项目名完整换行。项目列表独立滚动，新建名称输入框与操作按钮始终位于列表下方。空项目、无当前项目和目标项目被删除均有可继续操作的入口。

未保存的线路或批量表单在请求切换时先确认，取消确认保留填写内容。打开选择弹层时中断待完成的图片导出；切换项目后清理旧搜索计时器、材料视图和报告缓存，并忽略旧项目的迟到加载结果。选择正在查看的同一项目不会清空当前搜索和内容。

本轮没有修改 `utils/`、产品数据、既有接线助手页面、计算基准或存储结构。线路仍保存在对应项目的 `wiringSchedule` 中，没有新增全局线路表或数据迁移。

## 修改范围与验收

主要修改为 `pages/tools/tools.*`、`pages/projects/projects.*`、`pages/project-wiring/index.*` 和项目详情入口文案 `pages/records/project.wxml`。测试位于 `tests/project-wiring-entry-test.js`、`tests/project-wiring-page-test.js` 和 `tests/release-check.js`；README、CHANGELOG、交接说明同步更新。

重新编译后可按以下步骤体验：

1. 工具页直接打开通道与线缆，确认进入当前项目；没有项目时，直接在弹层新建。
2. 从项目卡点击布线，确认进入对应项目；点击报告仍打开原有详情。
3. 在布线页切换项目并添加一条测试线路，确认它只出现在选中的项目中。
4. 返回项目首页检查线路数，再切换常用收藏，确认原收藏仍可使用。
