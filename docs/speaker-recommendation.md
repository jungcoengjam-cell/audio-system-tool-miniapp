# 会议室音箱库组合推荐

本功能是“会议室扩声预估”的进阶结果。它只推荐普通矩形会议室的定覆盖点声源主扩与后区补声候选，**不自动搭配功放**。

## 适用范围

- 平顶、单层、规则矩形会议室或培训室；
- 场地面积不超过 300 m²、服务纵深不超过 20 m、层高不超过 6 m；
- 已登记角色、标称 H/V 覆盖角和最大声压字段的产品；本轮最大声压测试口径仍需按资料审计结果补核。

线阵列、音柱、超低、中置、台唇补声、两侧补声、覆盖角可变产品，以及未核验覆盖角或最大声压级的产品，不参与此模块的自动推荐。它们需要更多安装和声学变量，应由方案工程师专项设计。

## 主扩筛选规则

主扩必须同时满足：

```text
登记的最大声压字段 >= 场地预估的单只主扩 1 m 所需能力
标称水平覆盖角 >= 页面计算出的未舍入水平几何最低需求
标称垂直覆盖角 >= 页面计算出的未舍入垂直几何最低需求
```

报告型会比较 6 组有限的对称前置候选：`0.25/0.75`、`0.125/0.875`、`0.375/0.625`，每组包含正后方指向和由本服务半区四角水平角的最小/最大值取中线的指向。每个候选抽查首排、中排、末排的半区边界、中线与源轴线，并用完整 yaw/pitch 变换得到 raw H/V 几何最低需求。

候选排序先看是否存在同一已登记主扩型号同时包络 raw H/V 几何需求，再比较相对产品库最大 H/V 的 H/V 正超角归一化合计、最远声程和距离变化，最后以输入顺序稳定打破平局。这个有限集合的选中结果不能写成全局最优或工程最优。`60°/90°/120°` 是显示档位；产品筛选使用 raw 角度，因此实际 `98～99°` 的需求可以由标称 `100°` 产品满足，即使显示档位为 `120°`。水平需求超过 `120°` 或垂直需求超过 `90°` 时停止自动布置。

候选型号按能力余量和标称角余量展示最多三套替代方案。每套方案默认左右主扩各一只；`coverageVerification` 固定为 `unverified`，`qualificationStatus` 为 `provisional`，表示资料和现场声学覆盖仍需核验。

当前已登记的主扩候选：`KF-D10F`、`KF-D12F`、`KF-D15F`、`KF-D12H`、`KF-D15H`。最大声压测试口径仍按 [`venue-speaker-data-audit-2026-09-14.md`](venue-speaker-data-audit-2026-09-14.md) 待核对。

## 后区补声与安装距离

页面先根据前后排直达声差判断是否需要补声；本轮未优化补声数量判断，仍按既有前期规则执行。需要时，以后区补声的声压能力需求筛选已登记型号。

补声距离以主扩安装基准面为起点，沿场地纵深量取。它不按听音区中点划分，而以主扩相对首排的真实三维自由场直达声衰减作为交接参考：

```text
首排三维参考声程 r0 = hypot(首排距离, 音箱中心与听音耳高的高度差)
第 n 组目标声程 rn = r0 × 10^(6n / 20)
第 n 组补声纵距 = sqrt(rn² − 高度差²)
```

实际反推会把音箱中心到听音耳高的高度差纳入同一声程，再得到纵向安装距离；末端会预留既有裁切距离。计划源同时保留 `mainToFillDistanceMetersRaw` 和显示用的 `mainToFillDistanceMeters`。若补声组无法保持正值、严格递增、组间至少 0.1 m 且显示距离为正，结果停止自动补声并给出几何错误，避免计划阶段把不同组夹到同一位置。

页面会标明对应的主扩衰减值与负责声区。`6 dB/12 dB` 交接距离只用于粗略确定补声安装区域，本轮没有优化这些安装参考规则，**本模块不计算延时**。实际延时、相位与电平应在安装完成后，按实际主扩/补声位置进行现场测量与调试。

当前已登记的补声候选：`KS-08AT`、`KF-D10F`、`KF-D12F`；最大声压测试口径仍待核对。

## 边界与复核

推荐结果不是工程验收或最终方案。工程师仍需复核安装位置与高度、覆盖交叠、扬声器指向、功放通道与阻抗、DSP 分频/延时/限幅、房间声学和现场多点测量。

若结果的 `reviewWarnings` 显示“无匹配”，表示当前登记的点声源库不能在最大声压字段和标称 H/V 角内满足 raw 几何需求；此时应补充核验或进行专项选型，而不是降低条件后强行推荐。距离图使用等向距离能量示意，不能把图形重叠写成真实干涉或合格声场。结果里的 `source.aimDownDeg` 和 `source.aimYawDeg` 是计划与理想角包络共同使用的未舍入姿态，`aimDepthMeters` 仅保留为兼容字段。
