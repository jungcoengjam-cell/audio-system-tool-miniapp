# 项目布线初版 · 2026-09-20

状态：本地未发布功能。正式版本仍为 `5.0.1`，未上传或发布此次改动。

## 入口和初版范围

项目详情提供「通道与线缆」入口。工具页音频行新增「通道与线缆」，与「接线助手」相邻并排在前两位；点击「通道与线缆」进入布线。项目首页每个现场项目卡上的「布线」操作也可直达。项目首页默认展示现场项目列表，可切换查看收藏；项目卡同时提供「报告」直达和线路数量。

从工具页直入时，如果存在全局当前项目就打开该项目；没有时在布线页底部弹层中选择或新建。布线页顶部也可在本页切换项目；普通选择只影响当前布线页，不修改全局当前项目。新建项目沿用既有的创建即设为当前项目行为。没有计算记录的项目同样可以添加线路。布线页使用微信原生导航栏，页面内提供「线路 / 材料」两个视图。

本轮双入口更新不改变布线数据结构、存储或算法；项目布线仍未发布，正式版本号保持 `5.0.1`。本轮验收记录见 [`wiring-entry-update-2026-09-20.md`](wiring-entry-update-2026-09-20.md)。下方验证数字和包体数据属于项目布线初版验收记录，不代表本轮入口更新的验证结果。

- 每条线路记录用途、两端设备与端口、制作方式、线材规格、两端接头、长度、状态和备注。
- 新增、编辑、复制、删除、关键词搜索；输入设备时可复用本项目中的名称和端口。
- 一次批量添加 1～32 条，先预览递增的端口号再确认；每个项目最多 200 条。
- 自动线号从 A001 开始。删除不重排，复制使用新线号、重置为待施工，并在用户确认保存后写入。
- 材料区分别汇总成品线、现场制作线材、散装接头和双端线号。
- 复制文字及生成线路明细、材料清单、双端线号图片；长清单分页，图片可逐张预览、保存或转发。

## 数据和数量规则

线路保存在对应项目对象的 `wiringSchedule` 字段中，内部版本为 1。没有新建全局存储键，也没有把线路登记成计算记录或修改原有 `MODULES`。旧项目首次打开时不会自动写入空布线表。资料仍只保存在本机，删除项目会一并删除其布线资料。

保存依据进入页面时的明确项目 ID，重新读取项目并核对布线 revision。保存只写一次项目列表；项目删除、版本冲突、存储读取失败、未知版本、格式异常或写入失败时返回错误，保留原资料。写入失败不更新界面上的已存线路或缓存。项目首页与详情只接收布线数量摘要，不重复下发全部线路。

长度留空为待确认；填写值必须大于 0、不超过 1,000,000 m，最多两位小数。不接受指数、负值或非文本值，不把未知长度计为已知 0 米。`8`、`8.0`、`08.00` 使用同一长度归类。

成品线按线材、规格、两端接头及单条长度分组计条数，端头已包含在线缆内，不再追加散件。现场制作线按线材与规格汇总已知米数，并单列未知长度条数；其两端接头另行计数。线长来自手工录入，不自动添加施工余量。每条线路生成两份标签，分别注明本端和对端。

本模块整理点到点布线资料，不判定电气兼容性，不生成焊接方案，也不自动计算线径、衰减或线缆实际长度。现有接线助手仍负责接法查阅；本次没有修改它、计算算法、产品库或 DSP 校准值。

## 界面和独立复审

使用浅灰背景、白色卡片、蓝色主操作及轻量底部工具栏，并适配深色主题。录入表单独立滚动；底部操作等宽等高。页面保留原始数据在逻辑层，列表只下发显示字段，材料视图按需整理。报告根据内容调整高度，不用大块空白强撑固定尺寸。

复审中修正了复制线号被重新使用、批量前缀分隔空格丢失、非法长度被当成空值、导出标签类型不匹配、生成中离开页面的加载提示未清理，以及材料单位重复等问题。生成报告的迟到回调受到页面隐藏、卸载和数据变更检查，避免旧图片重新弹出。

## 初版验收建议

1. 建立一个测试项目，进入布线，添加两条调音台到处理器的线路。
2. 复制一条并修改端口，保存后删除另一条，确认原有线号未被重排。
3. 批量添加两条线路，先预览端口递增顺序，再确认保存。
4. 添加一条现场制作线，长度留空，查看材料区是否显示待确认，且成品线没有重复计算接头。
5. 分别导出线路表、材料表和双端标签，测试保存、转发以及退出页面后重新进入的数据保留。
