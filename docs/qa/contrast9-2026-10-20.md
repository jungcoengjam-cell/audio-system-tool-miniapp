# DMX 选中态文字对比度修正

本批只调整 DMX 地址页两个已绑定选中态的局部颜色：灯具分类和通道速查按钮。WXML 绑定、数据、通道含义及计算逻辑均未改变。当前 WXSS 在 dark theme 块之后声明两类选中态颜色，并把选中分类数量文字的有效 opacity 从通用分类文字规则中覆盖出来；未选中分类仍使用原有通用样式。

对比度契约按页面当前浅色与深色背景、两个真实 modal、WXML 祖先链和 CSS 最终级联计算。测试读取分类数量匹配的通用与选中文字规则，合并其 color/opacity；没有文字颜色声明时使用实际选中项颜色。普通动效按 modal 入场 keyframe 结束值计算，减少动态效果模式按静态 modal 样式计算；当前非文字祖先及 modal 稳态 opacity 必须为 1。页面覆盖层从现有 rgba 背景与页面底色合成。测试中的正例只要求实际绑定角色达到 4.5:1，不把本次实现色值当作长期色值合同。

独立复算的当前有效配色是白字与 `#005eb8`，分类文字、分类数量和通道速查三个角色在浅色、深色主题均为 6.37673806:1。原有白字与 `#007aff` 的对比度为 4.01697578:1；通用分类数量文字的 0.75 opacity 若用于选中项，在当前颜色下为 4.29436918:1。把 modal 稳态 opacity 降至 0.25 后，分类选中态在浅色/深色页面覆盖层上的对比度分别为 1.70486222:1 和 1.73026397:1，作为父层合成的失败控制。原始独立计算结果保存在 B9 `logs/candidate-contrast9-independent-metrics.json`。

局部验证：`node --check tests/closeout8-contract-regression.cjs` 成功；`node tests/closeout8-contract-regression.cjs` 为 14/14 通过，日志保存在 B9 `logs/candidate-contrast9-focused5.stdout.raw` 与 `candidate-contrast9-focused5.stderr.raw`。生产 WXSS 增加 137 字节。

这些结果是源码级级联和颜色计算，以及本地 focused 契约验证；不代表微信原生设备验收，也不代替完整注册套件或正式 `release-check`。完整套件、正式门禁和本地渲染验收由 B9 主验证报告记录。
