# 型号规格区域展示调整

本轮根据紧邻对话的规格录入需求，先优化单条新增、编辑及批量添加中的型号规格区域。

- 快捷规格改为两列等宽、等高的圆角选项，普通项使用中性底色。
- 型号与芯数、截面积分为两行显示；型号至少 13 px，副行至少 12 px。
- 当前规格与选项完整值相同时显示淡蓝底、蓝色文字与勾选标记；手动填写其他值后高亮自动消失。
- 输入框仍可自由编辑，两个表单共用相同样式，适配浅色和深色。

修改 `pages/project-wiring/index.js`、`index.wxml`、`index.wxss`。新增的 `specOptionViews` / `batchSpecOptionViews` 仅从已有规格字符串派生显示字段，原有规格集合、输入事件、保存、取消、复制和批量预览流程保持不变；弹层滚动结构未修改。核心算法、产品资料及存储规则未变。
