# 项目布线首次使用体验改进

本轮调整项目布线页的表单提示、分组阅读、导出入口和报告保存操作，帮助第一次使用的人理解线材端头、重复布线提示和多页报告。

线路表单仍只要求来源设备、来源端口、去向设备和去向端口，空白及纯空格仍不通过。缺项现在会逐字段标红、显示具体缺项，并滚动到第一个缺项；通过输入或选用历史值补齐后会清除对应错误。成品方式、线材类型、默认规格和接头值保持原样。单条与批量表单均说明初始线材信息仅供填录，端头填写线缆侧接头，不代表设备插座。

批量预览会把来源设备、来源端口、去向设备、去向端口都相同的已有线路列为可能重复，并在对应预览行显示已有线号。提示仅供现场核对，线号仍独立分配，用户仍可确认添加。编辑批量参数会清除旧预览和提示。

材料页将现有扁平材料行按“成品线、散线、散线端头、线号”显示分组标题；线号组注明用于线缆两端贴签。底层材料计算、条目顺序和扁平行数量保持不变。线路页导出入口移到标签栏下方，方便长列表用户使用。材料页的操作改为“导出材料图片”和“复制全部布线文字”。

报告预览会显示当前页与整份报告页数，并说明图片可逐页转发。用户可以保存当前页，或串行保存当前报告的全部页。成功页只在当前页面会话中记录，失败后可继续保存剩余页；权限失败提示用户手动到微信设置调整权限，取消和普通失败也会停止队列并保留已成功页。停止、关闭预览、隐藏、卸载或生成新报告都会让旧队列失效；已发出的相册请求无法撤回，界面会提示当前图片可能仍会保存。缓存报告重开时，保存进度和提示会按当前请求与已完成页重新同步，不再显示已停止队列的旧进度。整份报告预览使用全部页路径，打开原图时可左右浏览。

项目选择按钮标为“切换查看”，并说明切换只影响当前页面；从工具重新进入仍按项目记录里的当前项目打开。工具页音频卡片下方补充通道与线缆的用途及其与接线助手的区别，本机保存提示出现在项目页和空项目提示中；无项目且列表读取结束时，选择弹层收紧到内容高度。

算法、报告生成器、产品数据、四项输入含义与校验、项目当前项和存储格式均未修改。可能重复的线路仍可添加；保存进度不写入项目或微信存储。
