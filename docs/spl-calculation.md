# 声压级与功率估算说明

## 1. 适用范围

本模块用于估算同型号音箱在说明书额定功率条件下、相同测量距离、自由场不同距离的理论声压级。

灵敏度不允许用户手动输入，只使用产品说明书中已确认的：

```text
dB @ 1W/1m
```

## 2. 计算公式

说明书额定功率下，1 m 理论声压级：

```text
SPL_1m = Sensitivity + 10 × log10(P_rated)
```

距离为 `d` 米时：

```text
SPL_d = SPL_1m - 20 × log10(d)
```

其中：

- `Sensitivity`：说明书灵敏度，单位 dB @ 1W/1m
- `P_rated`：说明书额定功率，单位 W
- `d`：测量距离，单位 m，第一版限制为 1 至 1000 m

## 3. 多只音箱叠加

每只音箱均按说明书额定功率工作时，先计算单只音箱的声压级，再按用户选择的叠加方式增加增益。

常规叠加（默认，适用于相位未知或常规分散布置）：

```text
Gain_distributed = 10 × log10(N)
```

同相叠加（理想，适用于等距离、同相、指向一致）：

```text
Gain_coherent = 20 × log10(N)
```

其中 `N` 为同型号音箱数量。数量为 1 时，叠加增益为 0 dB。

以两只相同音箱为例：

- 常规叠加：`+3.0 dB`
- 同相叠加：`+6.0 dB`

## 4. TS-803C 示例

说明书参数：

```text
灵敏度 = 95 dB @ 1W/1m
额定功率 = 300 W
```

在 4 m 时：

```text
SPL_1m = 95 + 10 × log10(300) = 119.8 dB SPL
SPL_4m = 119.8 - 20 × log10(4) = 107.7 dB SPL
```

页面显示为约 `107.7 dB SPL`。

两只 TS-803C、各自额定功率、同样在 4 m 时：

```text
常规叠加 = 107.7 + 3.0 = 110.7 dB SPL
同相叠加 = 107.7 + 6.0 = 113.7 dB SPL
```

## 5. 使用边界

- 结果是自由场理论估算，不是现场实时测量值。
- 多只音箱仅适用于同型号、每只到测量点距离相同的基础估算；不同距离、多型号或阵列角度差异不能用本公式直接替代。
- 常规叠加和同相叠加分别代表两种边界条件，实际阵列增益会随频率、摆位、相位和覆盖重叠变化。
- 音乐节目电平、DSP 输出、限幅器工作状态、室内反射和空气吸收都会影响现场声压级。
- 对于说明书没有整箱灵敏度的型号，模块不提供计算结果。

## 6. 听感与会议扩声参考

页面将当前计算结果转换为便于理解的声压量级提示，例如：

- 约 60 dB SPL：接近日常交谈量级。
- 约 80 dB SPL：明显偏响的演讲、培训或音乐量级。
- 约 100 dB SPL：高声压扩声量级，普通会议通常仅将其作为最大声压能力参考。

这是帮助理解的近似提示；不同频率成分、声源类型和持续时间会使实际听感不同。

会议类扩声的最大声压级数值可参考《厅堂扩声系统设计标准》GB/T 50371-2006（2024 年局部修订）表 4.2.3：

- 一级：最大声压级不低于 98 dB。
- 二级：最大声压级不低于 95 dB。

小程序只比较当前理论声压级与这两个数值门槛，不输出“工程达标”结论。规范评价还需要按规定测量最大声压级、传输频率特性、传声增益、稳态声场不均匀度和系统总噪声级。
