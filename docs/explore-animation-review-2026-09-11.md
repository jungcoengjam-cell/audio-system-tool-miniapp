# 探索页文章卡片动画重构

本次目标是让八张卡片通过清楚的变化说明主题，而不是仅让图形闪动。保留文章入口、原有卡片尺寸、底部静态倒影与毛玻璃，以及现场排查卡片。

## 演示验收标准

| 主题 | 画面必须说明的变化 |
| --- | --- |
| LED 安装 | 净屏与安装空位对比，再展示包边带来的外尺寸；超出提示与对应状态一致。 |
| 限幅 | 输入继续增大，输出达到阈值后保持；阈值依据仍由正文解释。 |
| 距离衰减 | 1 m、2 m、4 m 的读数按顺序突出，保留自由场点声源的适用条件。 |
| 线材损耗 | 同一负载的低阻线路中，用短粗与长细线的对比表现损耗差异；不添加未经计算的数值。 |
| 补声接力 | 主扩较弱区域由补声衔接，不将图中的位置表示为唯一安装点。 |
| 增益结构 | DSP 保留一次衰减，功放取消重复衰减；不把电平对齐等同于响度相同。 |
| 摄像机 | 目标不移动，摄像机后退，视场角不变，仍提醒水平和垂直方向都需校核。 |
| DMX | 以 16 CH 为例依次占用连续地址段，不将每台灯表示为只占一个地址。 |

## 验证范围

- 浏览器按实际 WXML/CSS 渲染，覆盖 320/430 逻辑屏宽、浅色/深色主题，以及循环中多个时刻。
- 检查图中文字边界、底部文字布局、上方动画启用、下方倒影静止及减少动态效果模式。
- 微信 WXML/WXSS 原生编译与完整 `node tests/release-check.js`。
- JS、算法、产品数据、文章路由与观察器生命周期保持原样。

浏览器模拟和模板/样式编译不能代替微信真机的动画帧率、玻璃效果和完整调试流程。预览及日志保存于 `docs/recovery/pre-explore-story-animation/`。

## 包体记录原则

发布检查中的总源码体积阈值是项目内部预警，不是微信平台上限。先清除重复、无用规则并实测本次源码增量；若新增演示需要调整内部预警，记录实测值及原因。算法、JS、WXSS、WXML、媒体各分项限额不随本次动画重构放宽。

## 最终结果

- 修改源码：`pages/index/index.wxml`、`pages/index/index.wxss`；相应更新 `tests/release-check.js` 的探索页视觉结构断言与内部总源码预警。
- 主体样式和动画使用共用 `motion` 类与统一播放条件，重复动画定义已清理。离屏播放逻辑、页面 JS 和文章数据未改动。
- 独立浏览器复审通过 128 个动态卡片状态（8 张 × 2 种宽度 × 2 种主题 × 4 个时刻）；另检查减少动态效果下的 32 个静态卡片状态。
- 限幅输出与阈值位置、低电平跟随、摄像机和视场锥同步后退及固定目标、距离读数顺序、静态倒影、文字边界均已核对。
- 微信 WXML/WXSS 原生编译通过；完整 `node tests/release-check.js` 通过。
- 两个页面源码文件净增 4,794 bytes（WXML 2,449 + WXSS 2,345）。源码包实测 1516.5 KiB，内部总包预警从 1512 调整到覆盖本次实测的 1517 KiB；分项限额保持原值。
- 真机帧率、真机毛玻璃效果及开发者工具完整真机调试尚未验证；本次未发布或上传。
