# 布线表单键盘与图片导出修复

后续真机反馈发现本轮键盘方案仍会使弹窗整体移动，现已由[保持弹窗位置稳定的修正](wiring-keyboard-stability-2026-09-20.md)替代。导出修复保留。以下为第一轮实现与验证记录。

本轮处理用户反馈的“点击长度后页面上移过大、看不到输入框”及“导出类型切换后没有明显变化”。版本仍为 5.0.1，本地修改未上传或发布。

## 键盘与表单

单条新增/编辑和批量添加的输入框原先保留微信默认的整页键盘避让，与固定弹层内的滚动表单叠加。现在关闭这些输入框的自动顶页，按照键盘上方的实际可用高度调整弹层，并只在输入框超出内部滚动区时滚动必要距离。已可见的字段保持位置，输入内容时不重复测量。

窗口高度基于无键盘时的记录计算，并兼容系统已经缩小窗口的情况；键盘高度改变不会累计扣减。失焦、收起键盘、关闭弹层、隐藏或卸载页面后，旧的滚动测量不再写入位置。单条与批量合计 22 个输入控件采用相同处理，搜索框及项目选择输入保持原行为。

## 导出选择

选择器决定下一次生成的图片内容，上方线路列表不会跟随切换：

- 线路表：逐条展示来源、去向、线材及线路信息。
- 材料表：汇总成品线、散线及接头。
- 两端线号：按每条线路生成两端对应的标签。

修复真实按钮点击事件被当作导出类型的问题。原先点击事件对象会使报告构建回退到线路表；现在只接受三个明确的类型字符串，否则使用选择器的值。导出区域增加“图片内容”标记，按钮同步显示“导出线路表”“导出材料表”或“导出两端线号”。显式材料清单入口、缓存及迟到导出回调保护保留。

## 范围与验证

功能修改限于 `pages/project-wiring/index.js`、`index.wxml`、`index.wxss`。测试修改为 `tests/project-wiring-page-test.js`、新增 `tests/project-wiring-keyboard-test.js`，并根据实测包体更新 `tests/release-check.js` 的内部体积预警值。

独立检查保留原有 38 个控件的业务属性及绑定，53 个既有页面方法逐字未变，89 个受保护文件未改。计算算法、产品数据、材料汇总、报告内容构建、输入含义和存储规则保持原状。

23 个 WXML 与 24 个 WXSS 原生编译通过。独立报告集成检查使用相同线路和真实报告构建器，三种按钮选择分别得到线路明细、材料清单、双端线号标签，缓存类型也分别区分。自动化键盘测试使用模拟窗口和测量结果，不代表手机上已验证。

最终 `node tests/release-check.js` 退出码为 0，包含布线页面、键盘、存储与报告回归及既有计算模块。有效包为 2,098,788 字节，WXML 为 251,314 字节；内部预警值分别按实测向上取整为 2050 KiB / 246 KiB。独立比较确认只调整这两项预警及证据注释，其他发布门禁未改。

完整验证证据位于 [`verification/wiring-keyboard-export-2026-09-20/`](verification/wiring-keyboard-export-2026-09-20/)，包括 `binding-review.json`、`method-review.json`、`export-integration.json`、`native-compile.json`、`scope-review.json` 与最终回归日志。

本轮浏览器测试页创建失败，尚未做浏览器视觉或微信真机验收。真机重点复测：单条和批量的长度输入、切换到备注后收起键盘，以及分别导出三类图片。
