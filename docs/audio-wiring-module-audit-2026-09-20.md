# 接线助手本轮自检与 UI 修复记录（2026-09-20）

接线助手仍为本地未发布功能；正式版本保持 `5.0.1`，已上传正式版状态不变。本轮文档记录接线助手自检修复，不表示功能已发布。

## 本轮修复

- 生成图片期间打开接口选择器会使旧导出回调失效，避免迟到预览盖住选择器；打开、取消选择器或重选相同接口保留已完成的图片缓存，实际更换接口仍会清除旧结果。
- 对过期触摸、剪贴板及导图回调增加状态保护，避免页面状态变化或离开后迟到回调更新界面。稳定画布重绘的 `setData` 写入由 1 次降为 0 次；尺寸变化的 resize 只写入 1 次尺寸更新。此处是控制器调用计数，不是设备帧率或耗时测试。
- 收紧未完成条件时的页面留白，隐藏此时无效的视角切换；选择器用柔和填充和对勾呈现深色主题下的选中项，生成与复制按钮在不可用时降低视觉强调。
- 接口选择器突出具体接口名称和信号用途，删除重复的设备类型文字。功能图的点击区限制在中央水平线段，点公共端子或汇接节点时不再误选其他接线；接头视角保留逐线对应行的点击区。
- 去掉隐藏标题后残留的 24px 空白，同步调整绘制、高度和点击坐标；改善英文来源名称与中文标点断行。窄屏六线焊接图增加末行与注释间距，避免把 `TRS/TS` 拆开；报告来源标题改为“参考与适用边界”，明确 MLM82S 是不适用汇接方案的限制示例。
- 3.5 mm 立体声源接单声道输入时明确提示：直连接法只取一路，可能遗漏另一声道内容；需要两边内容时先由播放设备或混音器合成为单声道，L/R 不可直接并接。双 RCA/双 TS 分线仍分别传送 L/R，不显示“只取一路”提示。

## 真机验收重点

1. 生成图片后打开选择器并取消，确认原图片仍可使用；快速生成、切换接口时不出现旧预览。
2. 在连线图与接头视角间切换并滚动，检查画布、底部按钮与弹窗层级；六线焊接图底部说明完整。
3. 切换深浅色，检查选中接口与禁用按钮；确认未完成条件时不能复制或导图。
