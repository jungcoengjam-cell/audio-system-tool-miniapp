# TuneBuddy 5.1.0 更新说明（待发布）

## 微信上传更新说明

新增接线助手和项目通道与线缆管理，优化灯具导入、项目保存保护及多项工具的首次使用和输入体验。

## 本次范围

- 新增接线助手，按接口条件生成接线参考，并支持复制文本和图片。
- 新增项目内通道与线缆管理，支持线路编辑、批量录入、线号、材料汇总，以及线路和材料多视图导出。
- 完善布线编辑表单、输入控件和软键盘场景下的页面操作。
- 增加从灯具资料导入 DMX 配置的确认与保护流程，并在保存目标项目变化时保护现有项目数据。
- 优化 LED 大屏、会议室扩声、摄像机等工具的首次使用提示、输入校验和边界处理。
- 加强核心数值输入与派生计算的边界安全，保持有效输入的既有计算基准。

控制协议样本仍属于未发布开发资料，已移入 `tests/fixtures/control-protocol/`，不进入正式包，也不代表应用正式支持相关设备或协议。正式控制协议目录保持为空。产品资料日期及数量未变。
