## 发布隔离

`pages/control-protocol/development-sample.js` 和 `pages/control-protocol/draft-assets/` 都处于小程序可打包目录。页面仅在 `envVersion === "develop"` 时选用样本目录，但环境版本隐藏 UI 并不会从正式包移除这些文件。普通 `node tests/release-check.js` 会因检测到草稿数据/照片而拒绝通过；仅为了在本地执行其余回归，可设置 `CONTROL_PROTOCOL_ALLOW_DRAFT_SAMPLE_FOR_TESTS=1`，该覆盖只绕过草稿资源门禁，并会打印警告，不代表可以上传。

正式上传的清理步骤：先将 `pages/control-protocol/runtime-catalog.js` 切回只导入/导出 `./catalog` 的正式目录；把开发样本测试数据留在 `tests/` fixture 中或移除对应开发页面测试；再移除 `pages/control-protocol/development-sample.js` 与 `pages/control-protocol/draft-assets/`。之后运行不带环境覆盖的 `node tests/release-check.js`，确认检查通过，再进行上传。
