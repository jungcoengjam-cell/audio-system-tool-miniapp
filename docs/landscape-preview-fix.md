# 横屏位置图预览修复

## 问题

真机横屏打开位置图预览时，图片被放在通用纵向 `scroll-view` 中，标题、说明和操作按钮占用较多高度，导致 2400×1440 导出图在预览区域只显示中央约 230×140 的内容。导出图片本身的 2400×1440 分辨率保持足够。

## 处理

横屏预览 sheet 现在使用左右分栏：左侧媒体区占据剩余空间，图片宽高均为 100% 并使用 `aspectFit`，保证完整画布不裁切；右侧操作栏固定约 140px，标题和副标题采用紧凑字号，关闭、转发和保存按钮保持至少 44px 点击目标。sheet 和媒体区明确使用可用高度、`min-width: 0`、`min-height: 0`，并保留横屏安全区内边距。

预览图片仍绑定 `previewImage`，操作仍绑定 `shareImage`、`saveImage` 和 `closePreview`；遮罩关闭、事件阻止冒泡及触摸移动处理保持原语义。未修改 renderer、model、page-factory、算法数据、Canvas 绘制逻辑或 2400×1440 导出尺寸，也未改全局 `app.wxss` 的其他预览。

## 验证

- 原生 WXML 编译通过：21 项。
- 原生 WXSS 编译通过：22 项。
- 完整 `node tests/release-check.js` 通过；正式包 1511.8 KiB / 1512.0 KiB。
- 浏览器布局模拟通过：844×346（图片约 513×308）、667×280（约 403×242）、1024×700（约 836×502），关闭、转发、保存按钮均为 44px 且在窗口内。
- 浏览器模拟用于检查尺寸和布局，不能替代微信真机验证；本次未执行真机验证。
