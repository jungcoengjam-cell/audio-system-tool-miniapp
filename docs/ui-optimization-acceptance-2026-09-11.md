# 主要工具 UI 优化验收

2026-09-11。承接 `ui-design-audit-2026-09-11.md` 经用户同意的建议，由 Astra 规划与独立复审、Luna 实现和返工。正式源码已完成修改，未上传或发布。

## 页面变化

| 页面 | 已完成的变化 |
| --- | --- |
| 工具入口 | 音频、视频、灯光统一为两列卡片，八个工具通过纵向浏览可见；保留入口顺序、图标与资料库 |
| 摄像机 | 修复型号、类别和传感器空白显示；轻量 `selectedCamera` 与数量绑定；自定义参数来源分组、窄屏尺寸输入换行，错误提示置于输入卡内 |
| 限幅器 | 功放模式与灵敏度两列，HPF 独占下一行；放大关键标签；无效负载提示关联数量、连接与功放模式 |
| 增益结构 | 执行项改为标签在上、数值在下，突出 DSP 最终输出；保留三个执行值与一次衰减提醒 |
| LED 大屏 | 含包边安装外尺寸与净屏尺寸相邻突出；长拼装单元名称换行，窄屏预留字段两列；深色主题和三项指标末行完整显示 |
| 声压级 | 距离错误在输入处显示，参考长句降低视觉权重，操作区移至主结果后 |
| 线材 | 展示原有定压/定阻模式说明，错误放在线路条件内；图片、复制与记录操作紧随主结果 |
| 会议室 | 场景、等级与输入触控扩大；增加当前场景说明；两个分支的操作区前移，保留选型依据和布局折叠 |
| DMX | 扩大配置、方案与编辑器主要控件；方案错误可返回配置；A–D 容量字放大且可换行，350px 以下两列、宽屏四列 |

主要输入、选择器、按钮和结果操作采用至少 44×44 逻辑像素的触控目标。本轮修改合并进相应页面规则，共享样式、现有计算流程与图解按需展开保持原行为。

## 修改文件

- `pages/tools`、`pages/limiter`、`pages/spl`、`pages/cable`、`pages/gain-structure`、`pages/camera`、`pages/led-screen`、`pages/venue`、`pages/dmx-address` 内各自同名的 WXML 与 WXSS，共 18 个页面文件。
- `pages/camera/camera.js`：只补充当前选择设备的展示字段与同步，不把完整摄像机目录加入页面 data。
- `tests/release-check.js`：新增摄像机显示回归；将旧横滑、88rpx 布局断言更新为本次网格与实际触控设计；保留计算和存储数值预期。
- `CHANGELOG.md` 与本验收说明、`docs/recovery/pre-ui-optimization-20260911/` 中的验证材料。

## 独立复审与验证

- 修改前快照包含 149 份源码文件；哈希检查确认所有 `utils/`、`data/`、共享样式以及除摄像机外的页面控制器与修改前逐字节一致。生产改动限制在批准范围。
- 摄像机与修改前代码对比 66 种状态，覆盖 26 款型号、多视角、自定义与错误输入：结果、校验提示、偏好字段、导出文字均一致；新增所选型号显示与选择一致。
- 使用真实页面控制器数据和 WXML/WXSS 在浏览器模拟 186 个状态：9 个页面、31 个场景组合 × 320/375/430 宽度 × 浅深主题。涵盖选择器、长名称、非法输入、两种会议室场景、DMX 编辑器及四域方案。
- 上述模拟无缺失表达式绑定；被测关键字段无横向溢出；被测可交互控件边界均至少 44×44。复审默认页面、深色结果、错误态、展开态，并修复摄像机错误提示遗漏、LED 深色亮底和布局空洞等问题。
- 微信原生 WCC/WCSC 全量编译通过：21 份 WXML、22 份 WXSS。
- `node tests/release-check.js` 全量通过，含八个计算模块、产品参数、记录与存储、报告绘制、DMX 布局及文章演示数值回归。

## 包体与验证边界

正式包实测 1,557,951 bytes（1521.4 KiB），较本轮前 1,553,468 bytes 净增 4,483 bytes。内部总源码预警取下一整数 1522 KiB；JS、WXSS、WXML、媒体及单文件分项门槛不变。该内部预警不代表微信平台上限。

保留算法、产品数据、输入含义、自动计算、防抖、校验条件、收藏和项目存储语义；未新增依赖、定时器或模糊效果。取消的“灯光开场清单”没有开发。

本次没有真机验证。浏览器模拟与原生模板/样式编译不能代替微信实际渲染、系统字体缩放、键盘遮挡、触控手感和运行性能检查；模拟图不包含原生导航、原生选择弹窗与 Canvas 实际绘制。
