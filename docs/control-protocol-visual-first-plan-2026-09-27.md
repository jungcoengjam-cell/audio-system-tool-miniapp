# 控制协议库：看图核对方案

## 已确定方向

- 首版面向小程序全部用户，覆盖常用中控设备；以手动浏览图库和现场核对为主，文字搜索辅助。
- 试跑阶段收到 itC KZX 柜体正面照、同柜 SmartPLC-F300 柜内照及 QN-PLC（全球款）说明书；用户确认两张照片是同一台柜，说明书适用于该柜，且该柜内 F300 样本所用协议已验证、准确无误。后续识别改为看控制卡照片，正面图仅留来源档案，不进入应用包；Smart-F100 仅作面板可见字样。F300 品牌、硬件/固件/协议版本、柜内卡片照片公开授权和具名正式复核仍待处理；正式目录保持为空。功能概念预览中的结构图不是实际设备识别证据。
- 协议资料散落在同事聊天和文件中。首版按静态内置资料设计，支持离线查找；尚未指定正式协议复核人。

## 首版用户流程

1. 从「工具 → 中控」进入「看图找控制卡」，手动浏览控制卡照片，并可用品牌、型号、别名搜索；「工具 → 资料」继续保留「产品资料库」。
2. 点开控制卡照片进入详情，以柜内控制卡照片和标识比对；外壳照片只归档为适用柜体关联，不作为识别依据。
3. 仅当该控制卡照片/标识可对应到唯一控制卡型号和版本，人工复核的控制卡→协议映射唯一，且协议来源、授权、复核及必要元数据完整时，详情才直显协议与复制摘要；当前正式 resolver 仍保留外观组→设备→控制卡→协议的一对一严格门禁。
4. 若控制卡型号或映射不唯一，或来源、授权、复核、版本及照片证据不完整，则显示具体原因并停止，不展示或复制命令；请联系设备维护人员。

## 同外观不同控制卡

控制卡照片与可读标签是用户现场比对的主要依据；控制卡型号或控制卡→协议映射不唯一时必须阻断，不显示或复制协议。外观组 ID 仅作内部关联键，不作为用户识别依据。每个设备变体和控制卡变体都有独立稳定 ID，并按品牌、型号、版本记录。当前图库点击后仅自动解析严格一对一关联；同一外观组如对应多个控制卡，详情说明无法确定并阻止显示或复制协议，不要求用户在小程序内选择型号或点击确认。未来若多个不同柜体复用同一控制卡，须先有可追溯证据并单独设计复用关系，当前不自动共用协议。

## 实拍采集清单

- 仅拍摄公司拥有或已获授权的设备，并遵守现场规定。开柜或拆盖仅由有资质人员在确认断电、安全的条件下进行；普通用户不打开带电设备。
- 控制卡正面和可读型号/版本标签为首要必拍内容；若安全、授权条件允许，可采集整体柜体照片作可选档案关联。控制卡内部照片必须由合格人员在安全条件下采集。
- 拍摄前检查画面；入库或发布前遮盖客户名称、项目地址、人员姓名、电话、网络地址、账号、二维码、序列号等无关敏感信息，同时保留识别所需的品牌和型号。
- 每张图片分别记录来源、时间、拍摄者、视角和归属 ID；公开前逐图确认授权与脱敏复核。型号不明、授权未确认或脱敏未复核的图片标记为待补，不展示、不参与匹配。

## 数据对应关系

| 记录 | 最小字段 | 关联规则 |
| --- | --- | --- |
| 外观组 | 外观组 ID、类别、外观摘要、唯一映射复核标记、映射复核人 ID | 外观组 ID 是内部候选关联键，不作为用户识别线索；录入 `directMappingReviewed=true` 与 `mappingReviewerId` 才能通过当前自动协议直显门禁 |
| 设备变体 | 设备变体 ID、外观组 ID、品牌、型号、版本、别名、资料状态 | 记录适用柜体关联；用户端以控制卡照片/标签识别控制卡，外壳相似不能推定控制卡或协议 |
| 图片 | 图片 ID、归属类型、归属 ID、视角、文件路径、来源、时间、逐图授权确认、逐图脱敏复核 | 控制卡照片归属于对应控制卡变体并作为主要现场比对依据；外观组/设备变体的柜体照片仅为可选内部关联档案，不用于识别控制卡；不跨变体继承或串用 |
| 控制卡变体 | 控制卡变体 ID、所属设备变体 ID、品牌、型号、硬件/固件版本 | 一个设备变体可关联多个控制卡变体；各自独立匹配，不按名称或外观自动合并 |
| 协议 | 协议 ID、适用控制卡变体 ID、协议版本、传输参数、指令、来源文件、复核状态、更新时间 | 必须精确关联控制卡变体及其版本；来源和修改历史可追溯 |

## 分期与验收

### P0：盘点、冻结首批清单、定义静态结构

- 从聊天和文件整理高频设备与协议原件；冻结首批清单，覆盖 LED 配电、音频 DSP、视频矩阵/摄像机、灯光/电源等类别，具体条目以实际设备清单为准。
- 为外观组、设备变体、控制卡变体、图片归属和协议定义稳定 ID 与关联规则；外观组仅作内部关联键，首版资料内置小程序，支持离线搜索。
- **验收：**首批清单每条资料都有稳定外观组 ID、设备变体 ID 和控制卡变体 ID；品牌、型号、版本字段可辨；同名但型号/版本不同的设备不会自动合并；控制卡照片和协议原件可追溯。

### P1：按冻结清单交付手动图库和现场核对

- 建立以控制卡照片/标签为主的分类图库和详情、品牌/型号/别名搜索；只在控制卡→协议映射唯一且完整时直显协议。外观组仅作内部关联键。
- 控制卡正面及可读标签照片是图库覆盖的必需项；只录入已授权的真实照片，缺少实拍时清楚标记待补，不用结构示意图冒充实拍。柜体外观照片可选归档为内部适用设备关联。
- **验收：**P0 冻结清单中每个目标控制卡的已授权照片覆盖率 100%；控制卡型号/版本可从照片或资料追溯；每张公开控制卡照片逐图确认授权并完成脱敏复核，记录归属类型/ID且不跨变体复用；每个可公开协议有唯一稳定 ID、标题、适用控制卡品牌/型号/版本、传输参数、完整命令、可读来源、具名复核人和最近更新日期；指定维护人员人工复核控制卡→协议映射；对冻结清单内所有多控制卡、多协议或证据缺失情形均明确拦截，错误自动匹配为 0；只有唯一、完整且映射已核验关联时协议直显，否则不显示或复制命令并提示联系维护人员；离线浏览和搜索可用。当前 resolver 的外观组→设备→控制卡→协议一对一门禁保持不变；未来多柜体共用同卡须经证据验证后另行设计，不视为当前已支持。
- 正式目录复核人尚未指定。用户确认这台 itC KZX 柜内 F300 样本协议已验证且准确，但正式收录仍须补齐设备/控制卡硬件及固件版本、可追溯来源、具名复核和逐图公开授权/脱敏记录。

### P2：使用反馈与可选增强

- 根据无结果搜索、缺图、现场型号不匹配和使用频次更新清单及资料版本。
- 未来可评估照片 AI 辅助提供候选，但仅在图库实拍充足、获授权且人工数据维护稳定后考虑；AI 候选不能成为协议直显依据，直显仍依赖控制卡照片/型号识别和人工复核的唯一协议映射。
- **验收：**资料更新均可追溯来源与版本；任何后续辅助能力保留未匹配时的拦截和维护人员核实路径。
