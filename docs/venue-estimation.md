# 会议室扩声预估

本模块用于**普通矩形会议室**的扩声能力初步预估。页面包含“报告 / 培训型”和“围桌讨论型”两种互斥模式；本文说明前置 L/R 主扩与后区补声的报告 / 培训型算法，围桌模式见 `discussion-meeting-estimation.md`。

## 适用范围

必须同时满足：

- 平顶、单层、规则矩形会议室或培训室；
- 场地面积不超过 `300 m²`（按长度 × 宽度的未舍入结果比较；结果中的面积显示字段仍按页面精度舍入）；
- 从主扩安装面到后区的服务纵深不超过 `20 m`；
- 层高必须高于既有顶棚净空预留 `0.3 m`；
- 层高不超过 `6 m`。

礼堂、音乐厅、剧场、阶梯/分层座席、阳台、复杂异形空间，以及超过上述边界的场地，不在本模块内。页面会停止输出自动组合，并提示由方案工程师按平面图、安装条件和预测软件进行专项设计。

这些边界是为了避免在变量不足时给出貌似精确的自动建议，不是国家标准的场地分级阈值。

## 输入

- 场地长度、宽度和高度；
- 主扩安装方向：短边前置或长边前置；
- 主扩至首排听音位置的距离；
- 主扩至最后一排听音位置的距离；
- 实际听音区宽度；
- 会议类扩声一级或二级目标。

首排、最后一排和有效听音宽度都是均匀度预估的必要参数。模块不再把舞台、走道、后墙空区或两侧空区默认当作听众区。

## 默认几何假设

1. 主扩为左右各一只，安装在选择的前置墙侧。
2. 音箱中心高度默认按 `2.5 m` 预估；若顶棚不足，则下调为 `场地高度 - 0.3 m`，听音耳高按 `1.2 m` 预估。层高更高不会继续抬高音箱安装高度。
3. 报告型会比较 6 组有限的对称前置候选：听音宽度左右比例为 `0.25/0.75`、`0.125/0.875`、`0.375/0.625`，每组分别比较正后方指向和半区四角水平角包络中线指向。候选仅表示本模块的几何比较集合，不是文献或工程规范，也不等于全局最优。
4. “实际听音区纵深”是首排至最后一排的前后范围；“主扩至最远点声程”按选中候选到采样点的真实三维欧氏距离估算，包含横向距离和音箱中心到听音耳高的高度差。首排参考声程同样包含高度差。
5. 所有声压计算均是自由场、等向点声源的距离能量示意，不包含房间反射、吸声、真实频段指向性、功率压缩或 DSP 处理；声学覆盖状态始终需要核验。

层高不高于 `0.3 m` 时，音箱中心高度无法满足既有顶棚净空假设，模块会停止输出报告型自动方案。`0.31 m` 仍按原有公式继续计算；这不是新的常规层高下限。

## 计算

### 最大声压级能力

```text
主扩 1 m 所需能力
= 所选等级的最大声压级目标
+ 最远听音距离造成的自由场衰减
+ 3 dB 前期预估余量
```

### 主扩覆盖角

候选主扩各自服务对应半区。每组候选会对半区首排、中排、末排以及左右边界、半区中线和源正前轴线（轴线在半区内时）采样，再用完整 yaw/pitch 变换求标称水平/垂直角包络。候选排序依次为：是否有同一已登记主扩型号的标称 H/V 角同时包络几何需求、相对产品库最大 H/V 的 H/V 正超角归一化合计、最远声程、距离变化，最后按输入顺序稳定打破平局。

```text
水平几何最低需求 = 选中候选采样点的最大标称水平角绝对值 × 2
垂直几何最低需求 = 选中候选采样点的最大标称垂直角绝对值 × 2
```

计算使用未舍入的输入距离。`60°/90°/120°` 仍可作为显示档位，但产品筛选使用未舍入的 raw H/V 几何需求；显示为 `120°` 不代表产品标称角就是 `120°`。需求超过自动范围 `120°H` 或 `90°V` 时停止自动布置并返回所需角度。若几何角满足而公司音箱库没有同时满足 H/V 与能力字段的候选，结果保留 `reviewWarnings`，并可继续给出需要工程复核的几何计划。

### 均匀度预检查与补声

```text
首排至后排直达声差 = 20 × log10(最远三维声程 / 首排三维声程)
```

页面采用一级 6 dB、二级 8 dB 的保守设计检查值：

- 不超过检查值：两只主扩可作为均匀度预估起点；
- 超过检查值但不超过检查值 + 8 dB：建议增加一对后区补声音箱；
- 超过检查值 + 8 dB：建议按两组补声预估，共预留四只补声音箱。

本轮未优化补声数量判定以及主扩衰减 `6 dB/12 dB` 的安装参考规则；它们仍是现有的前期几何启发式。纵向安装距离由同一首排三维参考声程反推，并保留未舍入的几何值供计划和统计使用。模块不计算实际 DSP 延时；延时、电平、相位和指向必须在实际安装后测量确定。

如果当前输入与既有末端预留条件组合后使补声安装距离不大于 0、显示距离不为正、组间不严格递增或间隔不足 0.1 m，模块会停止输出自动补声方案并提示几何条件不足，不会把音箱位置强行移动为其他距离。

这项检查只计算主扩直达声，用于触发补声建议；补声加入后不会仅凭此计算宣称系统均匀度已通过。补声高度、指向、电平、延时和相位需在实际安装后测量确定。它也不等同于国标的稳态声场不均匀度验收结果。

### 补声传播复核（已实现，未发布）

结果页可使用轻量传播复核摘要，复用现有源位置、源姿态和 `aimDepth` 参考排，只取听音区横向 `1/4`、`1/2`、`3/4` 三个点；该摘要不因展开动作必然构建完整 plan。展开布局图或复制完整结果时仍沿用原有按需构建/复用完整 plan 的流程。每个点从共同标称 H/V 几何包络内分别选择最近参考源：前级集合包含主扩和更靠前补声，当前级为当前补声，且记录源标签。

```text
deltaMs = (前级参考源三维声程 - 当前补声三维声程) / 343 × 1000
```

正值表示按几何声程补声先到，负值表示后到。没有共同几何范围的点不给 `deltaMs`；没有补声时不显示复核。该值是固定 `343 m/s` 假设下的声传播差，不是实际主导声源、等电平位置、系统总到达时间或 DSP 延时；`coverageEndDepth` 也不是声传播截止。真正 DSP 延时、电平、相位和电子处理延时必须实测。完整方法、来源和最终回归证据见 [`venue-handoff-review-2026-09-14.md`](venue-handoff-review-2026-09-14.md)。

## 距离衰减参考图

结果页会绘制矩形平面，为每只主扩与补声音箱编号，并以半透明理想角包络投影标示单只音箱的名义几何范围。投影固定在听音耳高平面，按 yaw/pitch 变换后的 `forward >= 0`、水平角和垂直角半平面裁切到房间矩形及源的覆盖终点；它不是实测有效声场。补声音箱在平面图中靠近左右侧墙绘制。灰色表示用户设定的实际听音区之外，不参与统计；听音区边界会同时标出首排、最后一排和有效宽度。图外尺寸线标注场地宽度、场地长度，以及从主扩安装面到每组补声的建议距离。底层颜色按等向距离能量示意显示所有音箱叠加后的直达声趋势。输出同时保留显示舍入值和供几何/统计使用的原始值，统计不依赖显示舍入。

颜色是基于简化自由场等向距离模型和源校准参考电平的预估分档，不代表实测 dB SPL；图中的几何角包络也不等于频段有效覆盖。该图不包含房间反射、扬声器真实指向性、真实补声工作电平、延时、相位或多只音箱干涉，全部声学覆盖状态仍为未验证，不能作为最终声压预测、声场均匀度验收或专业预测软件的替代品。

## 国标边界

标准等级不能仅凭本页面的场地尺寸和声压计算判定。国标声学指标还包括传输频率特性、传声增益、稳态声场不均匀度与系统总噪声级等，需系统调试后在多个测点现场测试并共同满足。
