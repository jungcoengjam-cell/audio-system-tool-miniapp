当前源码版本为 6.0.0。用户确认本次更新已全部通过真机验证。测试预览主包为 2,071,081 B（2,022.54 KiB），低于 2 MiB 上限 26,071 B（25.46 KiB）；完整发布回归 63/63 项通过。测试预览不等于微信开发版上传、提审或正式发布；当前均尚未进行，正式上传仍需微信服务端校验。

## 本次更新

- 全面更新工具、项目和依据内容体验，覆盖音频、视频、舞台灯光与中控现场工作场景。
- 整理项目现场工作流程：使用本地项目管理计算记录、接线方案与通道线缆，查看项目资料和线路汇总，生成项目报告。
- 更新 DMX 灯具资料、地址编址和灯位布局工具，支持围绕现场灯具进行配置、定位和校对。
- 更新摄像机视场角与安装规划工具，支持地面区域和垂直平面场景，并提供可视化结果参考。
- 纳入控制协议参考资料，包括 SmartPLC-F300 与麒麟 Kylin K100R 的人工参考内容；仅对应已确认的现场样本，不表示其他同型号设备普遍适用。
- 整理配套知识内容、产品资料浏览、常用收藏、记录恢复与结果报告体验，便于现场查询和复核。
