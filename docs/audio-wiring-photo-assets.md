# Audio wiring photo assets

The six solder-side production PNGs now each show one complete opened connector, including the insertion body and the exposed solder contacts. The Canvas and exported diagram draw that single image once per physical connector head; they do not repeat an independent full-head photo or crop a second contact detail. `contentRect` covers the whole source image, so the renderer keeps each connector's actual aspect ratio.

Required diagram behavior: show each physical connector head once, label split inputs L/R, and draw each connection as a visible wire from the actual output solder contact to the actual input solder contact. Selecting a wire emphasizes that same path and its photographed contact points; Canvas wires are the selection entry, with no separate clickable mapping rows. The user rejected a previous version that showed parallel labeled mapping lines instead of physical connections. Current implementation and verification status are tracked in the [direct-wiring QA handoff](qa/audio-wiring-integrated-2026-11-08.md); the prior proposal is archived as [rejected](qa/audio-wiring-parallel-mapping-rejected-2026-11-08.md).

Five images use adopted built-in ImageGen prompts; the RCA image was rebuilt from the existing full-plug photo without a new ImageGen prompt. The final files are indexed-color PNGs with transparency. Their generated source paths, adopted prompts, crop margins, output dimensions, byte sizes, and SHA-256 hashes are in the [integrated photo provenance JSON](qa/audio-wiring-integrated-photo-assets-2026-11-08.json). The ImageGen log did not retain the local paths passed in as reference-image inputs; the documented reference URLs are listed there. The PNGs match the recorded QA candidates byte for byte. Earlier candidate prompts remain under `tests/audio-wiring-refactor-2026-10-13/photo-plan/generated/` and `tests/audio-wiring-refactor-2026-10-16-ts-photo/generated/` as historical records; they do not describe the current complete-object assets.

The female XLR overview remains available for the endpoint selection card at [`overview/xlr-female-v1.png`](../pages/audio-wiring/assets/overview/xlr-female-v1.png). That card reference is not loaded into the diagram Canvas or report. The XLR male selector card continues to use the existing catalog image.

Pin labels combine the physical contact name with the applicable function where the model defines it—for example `T L`, `R R`, `S G` for stereo TRS, and `T +`, `R −`, `S G` for balanced TRS. Contact coordinates are visual anchors in the edited images, not dimensions or manufacturing tolerances. The terminal-block photo remains unchanged; its `+ / − / G` labels are a schematic order, not measured hole or screw positions. Confirm functions against the equipment silkscreen before wiring.

The companion [QA handoff](qa/audio-wiring-integrated-2026-11-08.md) records the current implementation status and limits. The historical parallel-layout verification does not establish acceptance of the direct-wiring revision. No new real-device test was run for this asset revision.
