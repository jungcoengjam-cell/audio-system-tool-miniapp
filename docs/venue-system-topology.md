# 会议室主扩与补声边界

“会议室扩声预估”不再尝试为大场地判断线阵列、中置、台唇、两侧补声或超低配置。音乐厅、礼堂等空间通常涉及阶梯座席、阳台、分层、反射面、吊挂高度、阵列角度及多个声区，单靠长宽高无法输出可靠方案。

本模块只采用以下基础架构：

- 左右各一只定覆盖点声源作为 L/R 主扩；
- 若首排与最远点直达声差超出会议类预检查值，则增加一组或两组后区补声；
- 不计算实际 DSP 补声延时；几何声传播差的独立复核见下方边界说明。

报告/培训型主扩位置与姿态会在 6 组有限对称前置候选中比较：听音宽度比例为 `0.25/0.75`、`0.125/0.875`、`0.375/0.625`，每组比较正后方和半区四角水平角包络中线指向。候选按同一已登记主扩型号是否同时包络 raw H/V 几何需求、H/V 正超角归一化合计、最远声程、距离变化和输入顺序排序；这是有限候选集的稳定选择，不能解释为全局最优。

主扩计划与报告投影使用完整 yaw/pitch 几何变换。投影是固定耳高平面的理想矩形角包络，按 `forward`、水平角和垂直角半平面裁切到房间与覆盖终点；底层声级图是等向距离能量示意。`coverageVerification` 保持 `unverified`，不把几何包络、颜色分档或源间重叠当作真实频段覆盖、干涉证据或合格声场。

## 补声交接参考

补声位置以主扩相对首排的自由场直达声衰减作为交接参考。本轮未优化补声数量及该参考规则：

```text
主扩衰减 = 20 × log10(交接点三维声程 / 首排三维声程)
```

程序使用 6 dB 作为第一组补声的交接参考点，使用 12 dB 作为第二组补声的交接参考点。这些是前期启发式参考，不是标准安装距离：

```text
r0 = hypot(首排纵距, 音箱中心与听音耳高的高度差)
rn = r0 × 10^(6n / 20)
第 n 组补声纵距 = sqrt(rn² − 高度差²)
```

页面展示的是沿场地纵深、距主扩安装基准面的声压交接参考点。它不是最终安装位置；补声音箱的高度、下倾角、实际电平及延时仍需在方案深化与现场调试中确认。

## 补声传播复核边界

传播复核在结果级复用既有源位置、源姿态和 `aimDepth` 参考排数据，横向只使用听音区的 `1/4`、`1/2`、`3/4` 三个点。详情和结果图摘要走轻量复核缓存，不因展开动作必然构建完整 plan；布局图展开和完整结果复制仍沿用原有按需构建/复用完整 plan 的流程。对当前补声，前级参考源集合是主扩与更靠前的补声；两侧均从共同标称 H/V 几何包络内选择最近的三维参考源，并记录源标签。

```text
deltaMs = (d_front - d_fill) / 343 × 1000
```

`d_front` 为前级参考源声程，`d_fill` 为当前补声声程。正值表示补声先到，负值表示补声后到；没有共同几何范围的点不输出毫秒值，没有补声则不显示该复核。该比较不是实际主导声源、等电平交接位置或 `coverageEndDepth` 责任截止，也不改变原有位置、数量、型号、级别、颜色或声级数据。343 m/s 只是假设声速，不能替代真实 DSP 延时、电平、相位和电子处理延时测量。详细符号、样例和验证栏见 [`venue-handoff-review-2026-09-14.md`](venue-handoff-review-2026-09-14.md)。
