## 已独立复现

### 知识文章退出后仍接收旧观察回调

`pages/knowledge/detail.js` 中补声文章使用的原理动画观察回调缺少 `destroyed` 守卫。退出页面后发送已排队的观察回调，仍会执行一次 `setData` 并安排一个定时器，定时器还会再次更新已销毁页面。阶段演示已有守卫，该旧原理动画分支没有一致处理。

- 复现：[knowledge-late-observer-before.json](recovery/pre-project-audit-20260912/knowledge-late-observer-before.json)。使用内存 VM 和假定时器，没有访问真实用户存储。
- 已修复：销毁后的观察回调、动画入口和已排队的延迟启动均不再写入页面或启动后续任务；正常首次播放、重播、暂停和重新显示有对应回归。

### 摄像机退出后旧 Canvas 查询仍恢复缓存并绘制

根代理使用本轮旧源码隔离回放“展开预览 → 查询排队 → 卸载 → 查询完成”，仍发生一次 Canvas `clearRect` 绘制，并重新写入 `_canvasCache`。此前子审查只列为可疑项，本轮补齐了当前旧源码的可重复时序证据：[camera-late-query-before.json](recovery/pre-project-audit-20260912/camera-late-query-before.json)。修复放在页面的查询/生命周期边界，纯绘制模块继续只负责绘图。
