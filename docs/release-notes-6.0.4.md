# TuneBuddy 6.0.4 更新说明

## 微信更新说明

1. 完善产品型号对照，支持通过现场设备的其他型号查找对应资料。
2. 限幅器、增益架构、声压级、摄像机及灯光工具支持使用其他型号搜索，方便现场选型。
3. 优化接线助手接线图，点击线芯可高亮对应焊点，并提升接头切换响应。
4. 优化收藏入口和项目报告加载，完善记录保存与恢复的稳定性。
