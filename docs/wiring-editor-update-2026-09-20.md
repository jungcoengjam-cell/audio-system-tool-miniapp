# 线路编辑表单整理

本轮调整“通道与线缆”的单条新增、编辑表单，保持现有圆角、柔和底色与蓝色主操作风格。

- 按“来源 → 去向”“线材信息”“补充信息”分组；设备、端口与对应端头放在一起，设备字段占较宽一列。
- 来源和去向均保留历史快捷值、自定义端头输入。长历史名称允许换行，端头选项允许多行显示。
- 制作方式与线材类型并排，型号规格独占一行，长度与状态并排；原有规格快捷项保留。
- 用途和备注合并到补充信息。底部固定为等宽、等高的“取消／保存”；编辑已有线路时，“复制线路／删除线路”放在滚动内容末尾。
- 输入框与端点分组使用不同底色，兼顾浅色、深色；编辑区域输入文字保留至少 13 px，按钮至少 44 px 高。

## 修改范围

页面源文件仅修改 `pages/project-wiring/index.wxml` 与 `index.wxss`，新增样式限定在 `.wiring-edit-sheet` 内。批量添加、材料清单、报告及其他页面的结构保持不变。页面 JS、核心算法、产品资料、输入含义、字段上限、校验条件和存储规则均未修改。

`tests/release-check.js` 仅更新内部包体预警值及测量证据位置，未放宽平台限制或改变业务检查。
