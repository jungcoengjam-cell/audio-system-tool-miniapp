# 接线助手：取消冷端悬空方案

本次按用户要求移除平衡输出接非平衡输入时的“冷端悬空”接法。改动属于本地未发布功能，版本仍为 5.0.1。

## 当前行为

- 只提供冷端与屏蔽分别引至非平衡输入端、在输入回路汇接的方案；仍需用户明确确认设备手册允许，不自动预选。
- 移除原选项、生成分支、对应摘要和冷端未接标记。传入旧 `coldOpen` 选择时保持 `needs-choice`，不生成接线或复制文字，也不自动改成另一接法。
- 连线图、接头视角、复制文字与导出图片使用同一模型。3.5 mm 只取一路时未选声道保持未接，以及双输入只接一侧时的未接标记，均保持原行为。
- 42 种接口组合仍有 21 种直接方案、21 种需要确认的组合；展开后的有效方案由 91 种调整为 67 种，其中 46 种需要完成条件选择。数量表示接法分支，不表示所有设备兼容。

取消功能选项不改变设备的电路要求。本助手保留的汇接方案仅适用于设备手册明确允许的情况；不能因接头是 XLR、TRS 或平衡端子就认定可用。

## 修改范围

- 生产代码仅修改 `pages/audio-wiring/wiring-model.js`；页面控制器、WXML、WXSS、绘图器和存储行为保持不变。
- 更新模型、页面、绘图回归测试，以及方法说明、README、CHANGELOG 和交接说明。
- 原有计算模块、产品数据及 +18.4 dBu 校准值不在本次修改范围。

## 独立验收

证据目录：[本次验证记录](verification/audio-wiring-cold-return-only-2026-09-20/)。此前的 [91 方案验收](audio-wiring-cross-2026-09-20.md)保留为历史记录。

- 独立针脚核对：67 种有效方案通过；被移除的冷端选择无法生成连线或复制，所有有效平衡转非平衡方案均连接热端、冷端和屏蔽。
- 与修改前模型比较：43 种不受影响的方案完全一致。
- 浏览器页面模拟：320/375/430 px、浅色/深色共 90 个页面状态，无绑定错误、横向溢出、低于 44 px 的点击区或同排结果按钮尺寸差异。
- 实际 Canvas 绘制：742 次页面/接头/导出绘制，无文字越界或文字互相遮挡。人工查看了确认前后页面、接头视角、复杂分线及深色导出图片。
- 微信原生编译器：22 个 WXML、23 个 WXSS 编译通过。

- 完整回归：`node tests/release-check.js` 退出码 0，包含接线模型、页面、绘图专项及所有既有计算模块检查。完整输出见 [release-check.log](verification/audio-wiring-cold-return-only-2026-09-20/release-check.log)。
- 最终范围检查：唯一生产代码改动为接线模型，其余 233 个已有非文档目录文件保持原哈希（其余差异为 3 个测试与 3 个主文档）；正式版本号仍为 5.0.1。见 [scope-audit.json](verification/audio-wiring-cold-return-only-2026-09-20/scope-audit.json)。
- 独立复审补回了原有无关旧选择、未选声道绘图，以及切换接法前后选中状态/迟到回调的回归覆盖，未通过删减这些检查放行。
