# 摄像机安装位置反算规则

## 模块用途与边界

本模块根据已知拍摄区域和镜头视场角，估算摄像机需要离目标多远、镜头中心多高，并校核能否完整取景。距离按理想针孔模型下独立的水平与垂直视场角约束求解，是当前模型下的理论最小距离，不代表耦合倾斜视锥或绝对真实安装最小值；机械云台可现场调整水平与俯仰，固定式/枪机和电子云台型号则输出初始俯仰角参考。结果不代表人脸、文字或细节的有效识别距离。

结果未计入镜头畸变、畸变校正、电子防抖裁切、数字变焦、分辨率、照度、压缩编码、现场遮挡和安装结构尺寸。最终点位必须用实际摄像机画面复核。

## 两种拍摄场景

### 地面区域

适用于会议桌、坐席区和舞台活动区。用户输入区域宽度、纵深和区域内人物/物体最高点。

- 摄像机默认位于区域宽度中心线，并朝向区域中心。
- 自动建议镜头中心高度为 `人物/物体最高点 + 0.5 m`，且不低于 `1.5 m`。
- 算法把近端/远端的地面点和最高点组成三维包络，同时校核水平视角和垂直视角。
- 输出的距离是摄像机到实际拍摄区前沿的水平退距。
- 自动高度是便于落地的安装建议，并非由视场角唯一决定；用户也可以切换为已有固定高度进行校核。

### 垂直平面

适用于屏幕、黑板、背景墙和舞台口。用户输入目标宽度、高度和底边离地高度。

- 摄像机默认位于目标宽度中心线。
- 自动建议镜头中心与目标中心等高，此时光轴可保持水平。
- 使用已有固定高度时，算法根据目标上下边缘的夹角计算所需距离；机械云台把俯仰作为安装后的取景动作，固定式/枪机与电子云台输出初始俯仰角参考。
- 输出的距离是摄像机到目标平面的水平距离。

## 构图安全余量

默认余量为 `10%`，用于吸收人物动作、安装误差和画面裁切。地面区域会扩大区域宽度、纵深和最高点；垂直平面会围绕目标中心扩大宽度和高度。页面可选 `0% / 5% / 10% / 15% / 20%`。

## 核心公式

已知目标宽度 `W` 和水平视场角 `θh`：

```text
水平所需距离 = W / (2 × tan(θh / 2))
```

对于任一目标点，其相对镜头的垂直方向角为：

```text
方向角 = atan2(目标高度 - 镜头高度, 水平距离)
```

所有目标点方向角的最大值与最小值之差，就是本次构图所需垂直视场角。程序先按水平视场角求出水平最低距离，再从这个距离起校核垂直包络：若已通过，就采用水平最低距离；若未通过，则向远端扩展并二分求出首次通过点。因此完整结果是水平、垂直两项约束同时成立时，当前独立水平/垂直视场角模型下的理论最小距离。垂直校核距离表示“满足水平约束后的垂直校核距离”，不是脱离水平约束单独求出的全局最低距离。机械云台不固定初始俯角；固定安装型号使用目标垂直包络中心作为初始俯仰角参考。

地面区域和垂直平面在当前几何布局下，水平下限之后的垂直包络至多有一个远端通过边界；若下限处失败，扩展后可用二分定位该边界。最终会用未舍入的计算距离重新计算两轴所需视场角，只有两轴都不超过输入视场角时才返回完整结果。页面距离保留两位小数，原始值用于校核并另存供复算；显示值不能作为现场安装的满足保证，实际点位仍需样机复核。

只有水平视场角时，程序仍按目标宽度计算“水平覆盖最低距离”，但不生成垂直覆盖范围，也不宣称它是完整安装距离。固定安装型号可根据镜头高度与目标中心给出初始瞄准方向，但上下边界仍必须等垂直视场角或样机画面校核。

已知有效传感器尺寸 `S` 和实际焦距 `f` 时：

```text
视场角 = 2 × atan(S / (2 × f))
```

所有三角函数在内部使用弧度，页面结果按需要保留一至两位小数。构图余量是用户选择的输入参数，不代表额外自动安全余量。

## 摄像机参数优先级

1. 库内摄像机由产品说明书同时明确给出水平和垂直视场角时，才输出完整安装计算。
2. 说明书给出水平角但缺少垂直角时，型号可参与水平覆盖预估；结果必须标注“非完整安装距离”和“垂直未校核”。
3. 不使用画幅比例、对角视场角或变焦倍数推算缺失的库内参数。
4. 变焦型号的安装距离统一使用说明书广角端；长焦端参数仅在产品资料库展示，不作为第二个安装距离选项，也不对中间位置插值。
5. 自定义“已知视场角”必须同时填写水平角和垂直角；“传感器 + 焦距”必须填写有效成像宽高，不能把 1/2.8 英寸等光学格式直接当作传感器宽度。

## 页面计算过程

结果页使用三段式图解公开实际计算过程，详细文字公式仍保留在复制结果中：

1. 俯视直角三角形把有效宽度拆成两半，直接标出“对边、邻边和半视场角”，解释为什么使用正切关系 `tan(θh ÷ 2) = (W有效 ÷ 2) ÷ Dₕ`。
2. 侧视包络图连接镜头与目标最高、最低边界；厂家垂直角完整时，从水平最低距离起校核垂直距离 `Dᵥ`，缺失时显示未校核提示而不绘制虚假覆盖。
3. 水平最低距离、满足水平条件后的垂直校核距离使用同尺度长度条比较；地面区域再以算式卡片加回有效纵深扩展所对应的前沿距离。

## 安装结构分类

- `机械云台`：镜头可物理上下左右转动，页面不要求固定初始俯角。
- `固定式/枪机`：镜头本体不能转动，页面输出初始俯仰角参考。
- `电子云台（固定安装）`：只能在原始画面范围内电子裁切或重构，不能替代物理转向，因此按固定安装处理。
- `混合镜头结构`：双镜头产品按当前选中的特写/全景镜头分别判断，不用整机标签覆盖单个镜头的实际结构。
