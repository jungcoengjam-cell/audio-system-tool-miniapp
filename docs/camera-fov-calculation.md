# 摄像机安装位置反算规则

## 模块用途与边界

本模块根据已知拍摄区域和镜头视场角，估算摄像机需要离目标多远、镜头中心多高，并校核能否完整取景。2026-10-15 经用户授权，新的计算版本将真实目标角点投影到含俯仰的相机坐标，在相机取景截面上加入宽高余量，再求解双轴约束。俯仰仍采用目标垂直方向角包络的中心，因此“理论最小”指该瞄准规则下的理想针孔模型，不是对所有安装朝向、遮挡与真实镜头的全局最优。机械云台可现场调整方向，固定式/枪机和电子云台输出初始俯仰角参考。结果不代表人脸、文字或细节的有效识别距离。

结果未计入镜头畸变、畸变校正、电子防抖裁切、数字变焦、分辨率、照度、压缩编码、现场遮挡和安装结构尺寸。最终点位必须用实际摄像机画面复核。

## 两种拍摄场景

### 地面区域

适用于会议桌、坐席区和舞台活动区。用户输入区域宽度、纵深和区域内人物/物体最高点。

- 摄像机默认位于区域宽度中心线，俯仰按真实目标垂直方向角包络居中。
- 自动建议镜头中心高度为 `人物/物体最高点 + 0.5 m`，且不低于 `1.5 m`。
- 算法把近端/远端的地面点和最高点组成三维包络，同时校核水平视角和垂直视角。
- 输出的距离是摄像机到实际拍摄区前沿的水平退距。
- 自动高度是便于落地的安装建议，并非由视场角唯一决定；用户也可以切换为已有固定高度进行校核。

### 垂直平面

适用于屏幕、黑板、背景墙和舞台口。用户输入目标宽度、高度和底边离地高度。

- 摄像机默认位于目标宽度中心线。
- 自动建议镜头中心与目标中心等高，此时光轴可保持水平。
- 使用已有固定高度时，算法根据目标上下边缘的夹角计算所需距离；机械云台把俯仰作为安装后的取景动作，固定式/枪机与电子云台输出初始俯仰角参考。
- 输出的距离是摄像机到目标平面的水平距离。

## 构图安全余量

默认余量仍为 `10%`，页面可选 `0% / 5% / 10% / 15% / 20%`。先投影真实目标所有角点得到取景包络，再将该包络的总宽、总高各乘 `1+m`，围绕包络中心均分。分母是未扩张的投影包络线性尺寸；例如总量 `10%` 等于每侧原尺寸的 `5%`，不是每侧 `10%`，也不是占最终画幅的 `10%`。

真实场地纵深、目标物理高度与地面锚点均保持输入值。余量不再扩大世界坐标中的场地纵深或把人物高度单向加到地面上。倾斜相机的法向截面与世界竖直立面不同，不能把参考图中的前立面直接当作镜头成像边界。

## 核心公式

世界坐标使用前向水平距离 `x`、区域宽度 `y` 和离地高度 `z`。镜头中心为 `C=(0,0,h)`，俯仰 `p` 为正向上：

```text
f = (cos p, 0, sin p)        # 光轴前向
r = (0, 1, 0)               # 相机右向
u = (-sin p, 0, cos p)      # 相机上向
s = (P-C) · f               # 光轴深度，须大于 0
q右 = ((P-C) · r) / s
q上 = ((P-C) · u) / s
```

地面场景投影真实盒体的八个角点，平面场景投影四个角点。俯仰由真实目标的垂直方向角最大值与最小值的平均值确定：

```text
方向角 = atan2(z-h, x)
p = (最大方向角 + 最小方向角) / 2
扩张后左右边界 = 包络中心右坐标 ± 包络半宽 × (1+m)
扩张后上下边界 = 包络中心上坐标 ± 包络半高 × (1+m)
左右边界须在 ±tan(θh/2) 内
上下边界须在 ±tan(θv/2) 内
```

程序先求解水平约束，再从该水平下限检查完整双轴约束；若已满足垂直约束就直接采用该距离，否则扩展上界并二分定位远端通过点。每个候选距离都重新计算瞄准角和投影。镜头高于或低于整个目标时，垂直约束可能同时存在近端和远端可行区；不能从零开始联合二分而跳过近端可行区。完整结果必须让扩张后的两轴投影边界同时入画。`verticalMinimumDistanceMeters` 继续表示满足水平约束后的完整校核距离，不是单独的垂直最低距离。

校核与绘图保留未舍入的距离、俯仰、目标尺寸和取景包络。非常接近垂直俯拍时，某个视场边界可能不在镜头前方与近前平面相交；图中会明确标注截面截取，不能把无穷交线画成任意地面角点。

当前版本 2 对页面、三维示意和分享报告使用同一展示对象。从未舍入的 `calculationDistanceMeters` 保守显示到 0.01 m（不足时向上到下一档）；求解器及原有 `primaryDistanceMeters` 数值字段保持不变，因此报告兼容字段仍为 4.65 m，当前最小距离可显示为 4.66 m。自动建议高度按 2、3、4 位小数逐级尝试，俯仰角按 1、2、3 位小数逐级尝试；固定高度完整保留用户实际输入文本（包含尾随零和长小数），不强制改写精度。精度候选按 `H2/P1、H2/P2、H3/P1、H2/P3、H3/P2、H4/P1、H3/P3、H4/P2、H4/P3` 顺序，固定高度只尝试 `P1、P2、P3`。

每个候选都把最终实际显示的距离、高度和带方向俯仰文本连同 `m` / `°` 单位重新解析，再投影所有真实目标角点并校核完整水平和垂直包络。比较阈值固定为 `1e-12°`，不通过扩大容差掩盖舍入差异。求解器边界搜索本身允许 `1e-10°` 数值残差，因此更严格的展示校核可能对贴近边界的输入给出警告；这表示当前展示组合未能通过本展示规则，不会回写或修正求解器结果。若精度阶梯仍无候选通过，页面、辅助文本、图像和记录文字显示同一“展示精度范围内未通过双轴校核”状态，并明确不得据此安装或形成安装建议。不得通过另搜距离、改高度或调整真实场景几何来消除警告。

展示校核只验证当前理想模型下显示数值的内部一致性，不是现场安装验收，也不覆盖遮挡、镜头误差或识别距离。三维场景继续使用原始 `worldDimensions`、精确计算距离与原始俯仰；展示副本只供文字、标签和状态使用，不替换求解结果、原输入、用户偏好、收藏或历史快照。历史版本保留原有显示方式，并明确标成历史参考，不宣称通过当前 v2 双轴展示校核。只有水平视场角的型号维持水平参考状态，不宣称垂直或完整覆盖已校核。

只有水平视场角时，只求解水平投影约束，不生成垂直覆盖面，也不宣称完整安装距离；镜头初始方向仅供参考。当前 v2 在此模式下仍完整保留固定高度输入文字，但不把它解释为俯仰或完整覆盖已校核。上下边界仍需厂家垂直视场角或样机画面校核。

已知有效传感器尺寸 `S` 和实际焦距 `f` 时：

```text
视场角 = 2 × atan(S / (2 × f))
```

所有三角函数在内部使用弧度，页面结果按需要保留一至两位小数。构图余量是用户选择的输入参数，不代表额外自动安全余量。

## 摄像机参数优先级

1. 库内摄像机由产品说明书同时明确给出水平和垂直视场角时，才输出完整安装计算。
2. 说明书给出水平角但缺少垂直角时，型号可参与水平覆盖预估；结果必须标注“非完整安装距离”和“垂直未校核”。
3. 不使用画幅比例、对角视场角或变焦倍数推算缺失的库内参数。
4. 变焦型号的安装距离统一使用说明书广角端；长焦端参数仅在产品资料库展示，不作为第二个安装距离选项，也不对中间位置插值。
5. 当前页面仅使用产品库，不开放自定义角度或传感器输入；保留的底层换算函数不构成页面入口，旧自定义记录保持明确的不支持状态。

## 页面计算过程

页面与分享图片共用一幅正交三维图，不再切换俯视/侧视或显示额外角度卡片。真实场地、镜头高度、前沿退距及两张光学截面使用同一世界坐标与屏幕比例。蓝色水平截面、紫色垂直截面共用镜头中心，并在实际近前平面结束。取景包络的青色内框与琥珀色外框位于相机法向截面上；0% 时省略重合外框与余量环。详细过程保留在文字结果中。

页面结果文字与可访问名称、图中距离/高度/俯仰标签及分享报告使用同一展示状态和单位文本。过长的固定高度仍完整保留在页面结果文字和报告数值栏；若图中无法在既定边界内清晰容纳，则图内提示查看图下结果文字，不以截断数值冒充已校核结果。分享报告对完整数值换行，不裁掉用户输入。

## 历史记录兼容

新配置在偏好中记录 `cameraCalculationVersion: 2`。打开收藏时，收藏快照保持独立不变，编辑器建立明确标记 `cameraCalculationVersion: 2` 的工作副本；打开收藏本身不会回写或迁移收藏快照。打开未版本化的历史项目记录时，只在编辑工作副本中临时补入版本 1 标记，使用保留的旧公式重现距离和俯仰；打开时不迁移或覆盖原项目快照。用户编辑计算输入后，工作副本进入版本 2；新的保存签名与旧记录分开。

旧版本地面余量为宽、纵深、最高点各乘 `1+m`，纵深前后各增加 `m×D/2`，前沿退距包含近端扩张；平面余量在世界竖直立面上按中心扩张。该旧路径仅用于历史重现，图中标注“旧版余量”，不把它重解释为新取景截面余量。

## 安装结构分类

- `机械云台`：镜头可物理上下左右转动，页面不要求固定初始俯角。
- `固定式/枪机`：镜头本体不能转动，页面输出初始俯仰角参考。
- `电子云台（固定安装）`：只能在原始画面范围内电子裁切或重构，不能替代物理转向，因此按固定安装处理。
- `混合镜头结构`：双镜头产品按当前选中的特写/全景镜头分别判断，不用整机标签覆盖单个镜头的实际结构。
