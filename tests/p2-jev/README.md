# P2-A 离线评估数据

这里维护一组固定 120 条的合成中文请求样例，用于检查未来工具路由、参数显式性和澄清判断。样例由编码代理依据当前项目源码撰写与复核；它们不是工程师真实对话，也没有经过人类领域专家背书，因此预设标签不应描述为已由专家确认的真值。`provenance` 固定为 `synthetic`。

P2-A 仅包含静态 JSON、校验器和冻结工具，不包含调用器、SDK 或运行时依赖。不得在此阶段调用 Jev、其他模型、网络服务或读取 API key/环境密钥。当前 `project.config.json` 的 `packOptions.ignore` 排除了整个 `tests/` 和 `docs/`，且生产入口没有导入 P2 文件，因此这套工具不会进入小程序发布包。若 P2-B 获批，凭据只能通过该次进程的环境注入；不得写入 `.env`、数据文件或日志。实际推理属于 P2-B，必须经过单独的人类审批；后续分歧记录在对应运行目录中，不能回写或静默替换这份冻结基线。

## 文件

- `dataset/audio.cases.json`：50 条音频相关合成样例。
- `dataset/av-and-controls.cases.json`：70 条音视频、灯光和控制相关合成样例。
- `rubric.v1.json`：字段注册表、模式依赖、缺省值和澄清规则。
- `questions.v1.json`：未来单例输入的 Choice、Noul 与 Score 定义；允许的输入状态仅为 `user_request`，不得传入金标或样例元数据。
- `validate.cjs`：纯本地数据校验和 canonical SHA-256 辅助函数。
- `freeze.cjs`：先验证，再以独占创建方式写出 `freeze.v1.json`；文件已存在时拒绝覆盖，没有强制覆盖选项。

## 使用

在仓库根目录执行：

```text
node tests/p2-jev/validate.cjs
```

冻结完成后可验证清单和所有源文件哈希：

```text
node tests/p2-jev/validate.cjs --require-frozen
```

只有在本批数据和规则完成独立语义复核后，才可创建冻结清单：

```text
node tests/p2-jev/freeze.cjs
```

该命令只在校验通过后创建基线，不会替代复核或批准 P2-B 推理。

`validate.cjs` 导出 `validateCases(cases)`、`loadCases(files)`、`canonicalDataset(cases)`、`canonicalValue(value)`、`hash(value)`、`hashDataset(cases)`、`expectedFileHashes(cases)` 和 `validateFrozen(cases, manifest)`。因此调用方可以在内存中检查畸形样例，无须更改数据文件。规范化顺序为：按 ID 排序样例，递归按键名排序对象，保留数组顺序，序列化为紧凑 UTF-8 JSON，并在末尾添加一个 LF。

## 样例和规则边界

十个核心工具类别各包含 10 条样例，覆盖十种主要表达类型；另有 8 条跨工具请求、6 条支持请求和 6 条无关请求。每条用户请求和理由均为合成中文文本。字段显式性只认可用户原话中明确给出的值、范围或选项，并要求 `parameter_evidence` 是原话的精确连续子串。目录查询、默认值和计算派生值不算用户显式输入；说出了越界数值仍算已提供，是否追问由对应规则决定。

Rubric 保留当前源码中的条件语义。例如，会议讨论场景固定使用 `voiceLift`，PAG/NAG 的 NOM 是同时开放并送入扩声的话筒数量；反算模式的摄像机目标距离是求解输出，正向校核时用户明确给出的距离仍算输入，`1/2.8` 格式不是传感器物理宽度；接头外形不能证明音频信号类型；冷端回路方案需要明确的手册许可确认；项目线路缺少长度可待项目记录，不因此强制澄清。目录型号只有在唯一匹配时才能补充资料，不能伪装成用户提供参数；多视角摄像机型号需明确视角，多模式灯具型号需明确通道模式。

冻结清单保存基线提交、案例规范化摘要哈希和两个数据文件、rubric、questions、校验器、冻结脚本及本说明的逐文件哈希。冻结只证明文件内容保持一致，不证明标签已经过人工专家认证。

未来 P2-B 每次运行结果写入 `docs/verification/p2-jev/<run-id>/`，包含运行配置、输入摘要、原始模型输出、解析结果、逐例对比、汇总指标及人工复核/分歧记录。运行结果只作为新证据；不得覆盖冻结清单或改写这组 P2-A 样例。

## 未来指标计划

这些指标仅供获批的 P2-B 报告使用；P2-A 不运行模型，也不预填任何指标值。

- 路由与澄清判断分别统计总体 micro 和按工具/类别的 macro 结果；跨工具混淆矩阵须包含 `multiple`、`unclear`、`other`。
- 参数显式性一致率的分母仅包含该例中适用且有冻结预期标签的字段。FPR=`FP/(FP+TN)`，FNR=`FN/(FN+TP)`；分母为零时记为 N/A。
- 歧义等级指标另在 `ambiguity_level >= 1` 子集中报告，不与“意图明确但缺必填信息”的澄清样例混为一类。
- 按 rubric 的低置信边界报告结果：Choice 或 Score 置信度低于 0.6；Noul 概率在 0.2 与 0.8 之间（端点不计入低置信区间）。低置信结果需单独人工复核。
